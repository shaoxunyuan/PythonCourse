# 课程介绍

## 课程名称

《Python 高级应用》

## 课程目标

通过一条贯穿全学期的真实病例数据项目，掌握 Python 编程与数据处理的基本能力，并逐步建设一个数据分析与智能报告平台。

## 你将学会什么

- Python 基础语法与常用数据结构
- 条件判断、循环与函数封装
- CSV / JSON / TXT 等文件处理
- 使用 pandas 做数据清洗、统计与可视化
- 调用大模型 API 生成分析摘要
- 搭建简单 Web 应用并完成在线部署

## 贯穿项目主线

本课程不以零散小例子为主，而是围绕同一份住院记录数据，从「一条病例」逐步扩展到「完整数据平台」。

详细数据背景见：[SOP0：认识我们的课程数据](../sop0-data.md)。

## 学习节奏建议

每次实验约 120 分钟，大致包括：

1. 教师讲授（约 30 分钟）
2. 核心实验（约 60 分钟）
3. 进阶任务（约 20 分钟）
4. 检查、讨论与作业说明（约 10 分钟）
