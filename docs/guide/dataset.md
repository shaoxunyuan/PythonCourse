# 数据使用说明

## 数据存放位置

原始数据统一保存在仓库根目录的 `data/` 中：

- `data/diabetic_data.csv`
- `data/IDS_mapping.csv`

不要把大型原始数据再复制到 `docs/assets/`，避免多份拷贝不一致。

## 下载方式

优先从 GitHub 仓库的 `data/` 目录下载原始文件。

完整背景介绍请先阅读：[SOP0：认识我们的课程数据](../sop0-data.md)。

## 使用原则

1. 早期实验可能先用少量病例样本，再过渡到完整 101,766 条记录
2. 一行表示一次住院记录（`encounter`），不是一名唯一患者
3. 遇到 `admission_type_id` 等编码字段，可结合 `IDS_mapping.csv` 解释含义

## 教学用途声明

本数据仅用于 Python 编程、数据处理和软件开发教学。

课程中的病例筛选规则、统计结果以及大模型生成内容，均不用于临床诊断、治疗决策或真实医疗活动。
