# 作业提交说明

## 统一提交方式

请按照**雨课堂**发布的作业要求提交。

本网站仅提供题目与实验说明，**不接收作业提交**。

## 本站可以做什么

- 查看实验题目与要求
- 查看示例代码与数据说明
- 下载课程数据（通过仓库 `data/` 目录）

## 本站不会提供

- 答案输入框
- 文件上传按钮
- 学生账户 / 在线保存
- 自动评分
- 通过 GitHub Issue / Pull Request 交作业

## 提交提醒

1. 按雨课堂截止时间提交
2. 按教师要求命名文件与压缩包
3. 不要在公开仓库中提交真实 API Key 或敏感信息
4. 作业标准答案不会放入本公开仓库
