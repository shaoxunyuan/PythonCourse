## 课程简介

本课程围绕一份真实住院记录数据，学习 Python 高级应用相关能力：数据处理、文件读写、pandas、可视化、大模型 API、Web 应用与在线部署。

整个学期将逐步建设一个「Python 数据分析与智能报告平台」。

```text
一条病例
  → 多条病例 / 列表与字典
  → 条件判断 / 循环 / 函数
  → CSV / JSON / 文件处理
  → 完整真实数据与清洗
  → pandas 与可视化
  → 大模型 API 生成摘要
  → Web 平台与在线部署
```
