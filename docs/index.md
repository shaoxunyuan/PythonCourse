# Python 高级应用实验教程

欢迎进入《Python 高级应用》在线实验教程。

## 课程介绍

本课程面向本科生，通过真实病例数据，学习 Python 基础语法、数据处理、文件读写、pandas、可视化，以及调用大模型 API、构建 Web 应用并完成在线部署。

本站用于展示课程内容与实验要求，**不接收作业提交**。

## 课程学习方式

建议按下面的节奏学习：

1. **理解**：先弄清本次要解决什么问题
2. **练习**：跟随示例动手写代码
3. **调试**：对照运行结果排查错误
4. **项目**：把本次能力接入贯穿项目
5. **综合应用**：用完整数据完成统计、报告与平台功能

## 贯穿项目

整个学期围绕同一份真实住院记录数据，逐步建设一个「Python 数据分析与智能报告平台」。

大致路径：

```text
一条病例
  → 多条病例
  → 列表和字典
  → 条件判断 / 循环 / 函数
  → 文件与 CSV / JSON
  → 完整真实数据与清洗
  → pandas 与可视化
  → 大模型 API 生成摘要
  → Web 平台与在线部署
```

开始实验前，请先阅读：[SOP0：认识我们的课程数据](sop0-data.md)。
