实验2：组合数据类型

在实验1中，一条病例用多个独立变量保存。字段变多、病例变多以后，用 list / dict 等组合类型组织数据更清晰。

本课目标 会用字典表示一条病例；会用列表保存多条病例；能完成增删改查、排序与简单统计；能使用嵌套字典
数据字段 patient_id、age、gender、time_in_hospital、num_medications、readmitted
与 diabetic_data.csv 含义一致
练习方式 按 1.1～1.8 顺序运行；做完练习再完成第 2 部分任务

1. 练习

1.1 从变量到字典

字典用「键 → 值」保存一条病例的多个字段，字段名就是键。

Step 1 / 用字典表示一条病例
patient = {
    "patient_id": 12345,
    "age": "[70-80)",
    "gender": "Female",
    "time_in_hospital": 8,
    "num_medications": 18,
    "readmitted": "<30",
}
print(patient)
print(type(patient))
Step 2 / 读取与修改字段
print(patient["gender"])
print(patient["time_in_hospital"])

patient["num_medications"] += 1
patient["readmitted"] = "NO"
print(patient)
Step 3 / 查看全部键、全部值
print(patient.keys())
print(patient.values())
print("gender" in patient)
print(patient.get("insulin", "未知"))  # 键不存在时返回默认值
检查点：type(patient) 为 <class 'dict'>；修改后 num_medications 变为 19，readmitted 变为 NO。

1.2 列表 list

列表有序、可变，适合保存一组数值或一组病例。

Step 1 / 创建列表并按位置访问
stays = [1, 3, 2, 2, 1]   # 前几条记录的住院天数示意
print(stays)
print(stays[0], stays[-1])
print(stays[:3])           # 切片：前 3 个
Step 2 / 增删与长度
stays.append(8)
print(stays)
print(len(stays))
stays.remove(3)            # 删除第一个值为 3 的元素
print(stays)
Step 3 / 简单统计
print(sum(stays))
print(sum(stays) / len(stays))
print(max(stays), min(stays))
检查点：能正确打印长度、求和与平均值。列表下标从 0 开始。

1.3 元组与集合

tuple 有序且不可变，适合固定组合；set 元素不重复，适合去重。

Step 1 / 元组：固定字段组合
record = (12345, "Female", 8)
print(record[0], record[1])
# record[0] = 1   # 去掉注释会报错：元组不可修改
Step 2 / 集合：患者编号去重
ids = [12345, 12345, 67890, 12345, 99999]
unique_ids = set(ids)
print(unique_ids)
print(len(ids), len(unique_ids))
检查点：len(ids) 为 5，去重后 len(unique_ids) 为 3。这对应课程数据里「住院次数」与「患者人数」的区别。

1.4 病例列表 list of dict

多条病例的常用组织方式：列表里每个元素是一个病例字典。

Step 1 / 创建多条病例
patients = [

print(len(patients))

for p in patients:

1.5 增删改查

病例集合需要支持增加、删除、修改，以及按编号查询。

Step 1 / 增加一条病例
patients.append({
    "patient_id": 4,
    "age": "[60-70)",
    "gender": "Male",
    "time_in_hospital": 2,
    "num_medications": 7,
    "readmitted": "NO",
})
print(len(patients))
Step 2 / 按 patient_id 查询
target_id = 2
found = None
for p in patients:
    if p["patient_id"] == target_id:
        found = p
        break
print(found)
Step 3 / 修改查询到的病例
if found is not None:
    found["num_medications"] += 2
    print(found)
Step 4 / 按编号删除
patients = [p for p in patients if p["patient_id"] != 4]
print(len(patients))
for p in patients:
    print(p["patient_id"])
检查点：增加后长度为 4；删除 patient_id=4 后长度为 3；编号 2 的药物种数已增加 2。

1.6 提取、排序与统计

从病例集合中提取某一列、按住院天数排序，并统计 readmitted 分布。

Step 1 / 提取住院天数列表
# 先准备一份稳定的演示数据
patients = [
    {"patient_id": 1, "time_in_hospital": 3, "num_medications": 10, "readmitted": "NO"},
    {"patient_id": 2, "time_in_hospital": 8, "num_medications": 18, "readmitted": "<30"},
    {"patient_id": 3, "time_in_hospital": 5, "num_medications": 12, "readmitted": ">30"},
    {"patient_id": 4, "time_in_hospital": 8, "num_medications": 9, "readmitted": "NO"},
]
stays = [p["time_in_hospital"] for p in patients]
meds = [p["num_medications"] for p in patients]
print(stays)
print(meds)
Step 2 / 按住院天数从大到小排序
patients_sorted = sorted(patients, key=lambda p: p["time_in_hospital"], reverse=True)
for p in patients_sorted:
    print(p["patient_id"], p["time_in_hospital"])
Step 3 / 统计 readmitted 三类人数
counts = {"NO": 0, ">30": 0, "<30": 0}
for p in patients:
    key = p["readmitted"]
    if key in counts:
        counts[key] += 1
print(counts)
Step 4 / 找出药物种数最多的病例
max_med_patient = max(patients, key=lambda p: p["num_medications"])
print(max_med_patient)
检查点：counts 中 NO 为 2；药物种数最多的病例 patient_id 为 2。

1.7 嵌套字典

可以把一条病例拆成「基本信息 / 住院信息 / 用药信息」三层结构，便于分类管理。

Step 1 / 建立嵌套病例
patient = {
    "basic": {
        "patient_id": 2,
        "age": "[70-80)",
        "gender": "Female",
    },
    "hospital": {
        "time_in_hospital": 8,
        "num_medications": 18,
        "readmitted": "<30",
    },
    "meds": {
        "insulin": "Up",
        "diabetesMed": "Yes",
    },
}
print(patient["basic"]["gender"])
print(patient["hospital"]["time_in_hospital"])
print(patient["meds"]["insulin"])
Step 2 / 修改嵌套字段
patient["hospital"]["num_medications"] += 1
patient["meds"]["insulin"] = "Steady"
print(patient["hospital"])
print(patient["meds"])
Step 3 / 嵌套病例放进列表
nested_patients = [patient]
nested_patients.append({
    "basic": {"patient_id": 5, "age": "[30-40)", "gender": "Male"},
    "hospital": {"time_in_hospital": 4, "num_medications": 11, "readmitted": "NO"},
    "meds": {"insulin": "No", "diabetesMed": "Yes"},
})
for p in nested_patients:
    print(p["basic"]["patient_id"], p["hospital"]["readmitted"])
检查点：能正确读取 basic / hospital / meds 下的字段；列表中有 2 条嵌套病例。

1.8 综合：病例集合

把前面能力串起来：维护一份病例列表，完成查询、统计与摘要输出。

Step 1 / 完整示例
patients = [
    {"patient_id": 1, "age": "[50-60)", "gender": "Female",
     "time_in_hospital": 3, "num_medications": 10, "readmitted": "NO"},
    {"patient_id": 2, "age": "[70-80)", "gender": "Female",
     "time_in_hospital": 8, "num_medications": 18, "readmitted": "<30"},
    {"patient_id": 3, "age": "[40-50)", "gender": "Male",
     "time_in_hospital": 5, "num_medications": 12, "readmitted": ">30"},
]

# 增加
patients.append({
    "patient_id": 4, "age": "[60-70)", "gender": "Male",
    "time_in_hospital": 2, "num_medications": 7, "readmitted": "NO",
})

# 查询并修改
for p in patients:
    if p["patient_id"] == 3:
        p["time_in_hospital"] += 1

# 排序后输出摘要
patients_sorted = sorted(patients, key=lambda p: p["time_in_hospital"], reverse=True)
for p in patients_sorted:
    flag = "是" if p["readmitted"] == "<30" else "否"
    print(
        f"编号{p['patient_id']} | 住院{p['time_in_hospital']}天 | "
        f"药物{p['num_medications']}种 | 30天内再入院：{flag}"
    )

# 统计
counts = {"NO": 0, ">30": 0, "<30": 0}
for p in patients:
    counts[p["readmitted"]] += 1
print("readmitted 分布：", counts)
print("平均住院天数：", sum(p["time_in_hospital"] for p in patients) / len(patients))
检查点：按住院天数降序打印；编号 3 的住院天数已加 1；能看到三类 readmitted 计数与平均住院天数。
