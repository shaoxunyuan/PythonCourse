实验2：组合数据类型

从一条病例到一组病例：很多相关的数据怎样组织在一起？完成本节后建立「病例数据模型 V0.2」。

本课目标 掌握 list / tuple / dict / set；理解嵌套结构与 list of dict；能用组合类型表示一条与多条病例
项目阶段 V0.2 病例数据模型。字段与 diabetic_data.csv 含义一致
练习方式 按 1.1～1.15 顺序完成练习，再完成第 2 部分任务

1. 练习

1.1 为什么一个变量已经不够用了

上一节已经能够用多个独立变量表示一条病例，例如：

patient_id = 10001
gender = "Female"
age_group = "[70-80)"
time_in_hospital = 8
num_medications = 18
number_inpatient = 2
readmitted = "<30"

现在只有 7 个字段，看起来还不复杂。但真实 diabetic_data.csv 中，一条住院记录约有 50 个字段。如果同时管理 10 条、100 条病例，是否还要继续写：

patient1_id = ...
patient1_gender = ...
patient2_id = ...
patient2_gender = ...

相关的数据应当组织在一起。本节回答三个问题：

  • 一名患者有很多字段，怎样组织成一个整体？
  • 同时存在很多患者时，怎样把多条病例放在一起？
  • 不同的数据关系，为什么需要不同的组合数据类型？

1.2 什么是组合数据类型

上一节中的 10001、"Female"、8、True 都是单独的值。本节需要表示一组数据，或一组有关系的数据，例如：一名患者的多个字段、多个患者、多个年龄组、多个再入院状态。

本节重点：list、tuple、dict、set。

类型 主要特点 常见用途
list 有顺序、可以修改 一组病例、一组数值
tuple 有顺序、通常不修改 固定信息、固定配置
dict 键和值对应 一条结构化病例
set 不重复、无固定顺序 去重、集合关系
结论：没有一种结构永远最好。关键在于数据之间是什么关系。

1.3 list：创建、索引与切片

list 用于保存一组有顺序、可修改的数据。

Step 1 / 创建列表
ages = ["[50-60)", "[60-70)", "[70-80)", "[80-90)"]
stay_days = [3, 5, 8, 4, 10]
print(ages)
print(stay_days)
print(type(stay_days))
Step 2 / 索引（从 0 开始）
stay_days = [3, 5, 8, 4, 10]
print(stay_days[0])   # 第一个
print(stay_days[2])   # 第三个
print(stay_days[-1])  # 最后一个
Step 3 / 切片：取出一部分
print(stay_days[0:3])
print(stay_days[:3])
print(stay_days[2:])
检查点：stay_days[0] 为 3；stay_days[0:3] 为 [3, 5, 8]。

1.4 list：增删改与常用函数

Step 1 / 修改元素
stay_days = [3, 5, 8, 4, 10]
stay_days[0] = 4
print(stay_days)
Step 2 / 添加元素
stay_days.append(6)
print(stay_days)
stay_days.insert(1, 7)
print(stay_days)
stay_days.extend([11, 12])
print(stay_days)
Step 3 / 删除元素
stay_days = [4, 7, 5, 8, 4, 10, 6, 11, 12]
stay_days.remove(7)
print(stay_days)
last_value = stay_days.pop()
print(last_value)
print(stay_days)
del stay_days[0]
print(stay_days)
Step 4 / 常用内置函数
stay_days = [3, 5, 8, 4, 10]
print(len(stay_days))
print(min(stay_days))
print(max(stay_days))

检查点：对 [3, 5, 8, 4, 10]，长度为 5，最小 3，最大 10，总和 30。本节先用内置函数完成统计，暂不使用循环逐个累加。

1.6 tuple：一组固定的数据

有些组合数据创建后不希望频繁修改，可使用 tuple。

Step 1 / 创建与访问
age_range = (70, 80)
record_position = ("patient_nbr", "age", "gender")
print(age_range)
print(type(age_range))
print(age_range[0])
print(age_range[1])
print(len(age_range))
Step 2 / 观察不可修改
age_range = (70, 80)
# age_range[0] = 60   # 去掉注释后可观察报错
Step 3 / 解包（理解即可）
lower, upper = (70, 80)
print(lower, upper)
检查点：list 可以修改；tuple 通常用于固定、不希望修改的数据。数据结构的选择会限制允许的操作。

1.7 dict：字段和值的对应关系

dict 是本节最重要的结构之一。一条病例天然适合用「字段名 → 字段值」表示。

Step 1 / 从多个变量到一个病例字典
# 上一节写法
patient_id = 10001
gender = "Female"
age_group = "[70-80)"
time_in_hospital = 8

# 本节写法
patient = {
    "patient_id": 10001,
    "gender": "Female",
    "age_group": "[70-80)",
    "time_in_hospital": 8,
    "num_medications": 18,
    "number_inpatient": 2,
    "readmitted": "<30"
}
print(patient)
print(type(patient))

"patient_id" 是键（key），10001 是值（value）。完整结构是 key : value。

Step 2 / 基本访问
print(patient["patient_id"])
print(patient["gender"])
print(patient["time_in_hospital"])

1.8 dict：访问、修改与常用方法

Step 1 / get() 与方括号访问
print(patient.get("gender"))
print(patient.get("weight"))
# print(patient["weight"])  # 键不存在时会报错，去掉注释可观察差异
Step 2 / 修改、添加、删除
patient["time_in_hospital"] = 9
patient["comment"] = "Teaching example"
print(patient)
patient.pop("comment")
print(patient)
# del patient["comment"]  # 也可删除键
Step 3 / keys / values / items / update
print(patient.keys())
print(patient.values())
print(patient.items())

patient.update({
    "time_in_hospital": 9,
    "num_medications": 20
})
print(patient)
检查点：get() 在键不存在时通常更安全；本节先直接观察 items() 的结果，暂不使用循环逐项遍历。可用 update() 一次修改多个字段。

1.10 set：不重复的数据集合

set 主要用于去重与集合关系判断。

Step 1 / 去重
readmission_status = {"NO", ">30", "<30", "NO", "<30"}
print(readmission_status)

age_groups = {"[50-60)", "[60-70)", "[70-80)", "[70-80)"}
print(age_groups)
Step 2 / 添加、删除、成员判断
readmission_status = {"NO", ">30", "<30"}
readmission_status.add("UNKNOWN")
print(readmission_status)
readmission_status.discard("UNKNOWN")
print(readmission_status)
print("<30" in readmission_status)
Step 3 / 并集、交集、差集
group_a = {"A", "B", "C"}
group_b = {"B", "C", "D"}
print(group_a | group_b)  # 并集
print(group_a & group_b)  # 交集
print(group_a - group_b)  # 差集
检查点：集合中重复值会被去除；成员判断使用 in。set 没有固定位置索引。

1.11 四种数据结构怎样选

数据需求 建议结构
保存一组有顺序的病例 list
保存固定的年龄区间 tuple
保存一条病例的字段和值 dict
保存不重复的类别 set

若要保存「很多条完整病例」，常用做法是：外层用 list，每条病例用 dict，即 list of dict。

1.12 嵌套字典

字典的值还可以是另一个字典，用于表达数据的层级关系。

Step 1 / 扁平结构与嵌套结构
patient = {
    "patient_id": 10001,
    "demographic": {
        "gender": "Female",
        "age_group": "[70-80)"
    },
    "hospital": {
        "time_in_hospital": 8,
        "num_medications": 18,
        "number_inpatient": 2
    },
    "readmitted": "<30"
}
print(patient["demographic"]["gender"])
print(patient["hospital"]["time_in_hospital"])
检查点：先取出内层字典，再读取其中字段。

1.13 从一条病例到多条病例：list of dict

外层 list 表示有多条病例；每个元素是 dict，表示一条结构化病例。

Step 1 / 建立 patients
patients = [
    {
        "patient_id": 10001,
        "gender": "Female",
        "age_group": "[70-80)",
        "time_in_hospital": 8,
        "readmitted": "<30"
    },
    {
        "patient_id": 10002,
        "gender": "Male",
        "age_group": "[60-70)",
        "time_in_hospital": 4,
        "readmitted": "NO"
    },
    {
        "patient_id": 10003,
        "gender": "Female",
        "age_group": "[80-90)",
        "time_in_hospital": 10,
        "readmitted": ">30"
    }
]
Step 2 / 层级访问
print(patients[0])
print(patients[0]["gender"])
print(patients[1]["time_in_hospital"])

结构示意：

patients
│
├── [0]
│     ├── patient_id
│     ├── gender
│     ├── age_group
│     └── time_in_hospital
│
├── [1]
│     ├── patient_id
│     ├── gender
│     ├── age_group
│     └── time_in_hospital
│
└── [2]
      ├── patient_id
      ├── gender
      ├── age_group
      └── time_in_hospital

patients[0]["gender"] 的含义是：先从患者列表取出第一条病例，再取出该病例的 gender 字段。

说明：若有 100 条病例，是否还要手工写 patients[0]、patients[1]……？自动逐条处理将在后续「程序控制结构」相关内容中学习。本节不正式展开 for / while。

1.15 常见错误

错误 1：索引从 0 开始。patients[0] 表示第一条病例。

patients = [{"patient_id": 1}, {"patient_id": 2}]
print(patients[0])  # 第一条

错误 2：索引超出范围。

# 只有 3 条病例时，patients[10] 会报错

错误 3：访问不存在的字典键。

patient = {"gender": "Female"}
print(patient.get("weight"))
# print(patient["weight"])  # 可能报错

错误 4：list 与 dict 的访问方式不同。

# 列表：patients[0]
# 字典：patient["gender"]
# 不要写成 patient[0] 或 patients["gender"]（除非结构确实如此）

错误 5：tuple 不能像 list 一样修改。

age_range = (70, 80)
# age_range[0] = 60  # 会失败

错误 6：set 不能依赖位置索引。

status = {"NO", ">30", "<30"}
# print(status[0])  # 不正确的用法
print("<30" in status)

数据已经可以组织成列表与字典。若有 100 条病例，仍逐条写 patients[0]、patients[1]……并不现实；若还要自动找出住院时间 ≥ 7 天的病例，需要程序具备判断与重复处理能力。这些问题将在后续「程序控制结构」相关内容中继续展开。
