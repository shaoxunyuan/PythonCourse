SOP2：Python 数据结构与病例组织

病例字段越来越多、患者越来越多以后，怎样组织数据？完成后你将得到「病例数据模型」：能用数据结构表示多名患者与多条病例。

1. 从独立变量到字典

patient = {
    "patient_id": 12345,
    "age": "[70-80)",
    "gender": "Female",
    "time_in_hospital": 8,
    "num_medications": 18,
    "readmitted": "<30",
}
print(patient["gender"])
patient["num_medications"] += 1

2. list / tuple / set / dict

  • list：有序、可变，适合一组病例
  • tuple：有序、不可变，适合固定组合
  • dict：键值对，适合一条病例的多字段
  • set：不重复集合，适合去重患者编号
ids = [12345, 12345, 67890]
print(set(ids))
print(ids[0], ids[-1], ids[:2])

3. list of dict

patients = [
    {"patient_id": 1, "time_in_hospital": 3, "readmitted": "NO"},
    {"patient_id": 2, "time_in_hospital": 8, "readmitted": "<30"},
    {"patient_id": 3, "time_in_hospital": 5, "readmitted": ">30"},
]

# 增加
patients.append({"patient_id": 4, "time_in_hospital": 2, "readmitted": "NO"})
# 查询
one = [p for p in patients if p["patient_id"] == 2][0]
# 排序
patients.sort(key=lambda p: p["time_in_hospital"], reverse=True)
# 统计
avg = sum(p["time_in_hospital"] for p in patients) / len(patients)
