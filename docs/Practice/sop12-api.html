1.2 GET：公开 JSON 接口

下列公共接口无需登录。若网络不可用，改用本地 todo_1.json。

import json
from pathlib import Path
import requests

url = "https://jsonplaceholder.typicode.com/todos/1"
try:
    r = requests.get(url, timeout=10)
    r.raise_for_status()
    data = r.json()
except Exception as exc:
    print("在线失败，改用本地:", exc)
    data = json.loads(Path("todo_1.json").read_text(encoding="utf-8"))

print("编号:", data["id"])
print("任务:", data["title"])
print("完成:", data["completed"])
本地备份文件 todo_1.json
{"userId": 1, "id": 1, "title": "demo task", "completed": false}
检查点：无论在线或离线，都能读出三个字段。

1.3 请求参数：GET params 与 POST json

import requests

# GET 查询参数
r = requests.get(
    "https://jsonplaceholder.typicode.com/posts",
    params={"userId": 1},
    timeout=10,
)
r.raise_for_status()
posts = r.json()
print("条数:", len(posts))

# POST JSON 正文
r2 = requests.post(
    "https://jsonplaceholder.typicode.com/posts",
    json={"title": "course-demo", "body": "hello api", "userId": 1},
    timeout=10,
)
print("POST 状态码:", r2.status_code)
print(r2.json())
检查点：理解 params（拼到 URL）与 json=（放进请求体）的差别。

1.5 错误处理：超时、状态码、有限重试

import time
import requests

def fetch_json(url, retries=2, timeout=10):
    last_error = None
    for attempt in range(retries + 1):
        try:
            r = requests.get(url, timeout=timeout)
            if r.status_code in (401, 403, 429) or r.status_code >= 500:
                raise requests.HTTPError(f"HTTP {r.status_code}", response=r)
            r.raise_for_status()
            return r.json()
        except (requests.Timeout, requests.HTTPError, requests.RequestException) as exc:
            last_error = exc
            if attempt < retries:
                time.sleep(0.5)
                continue
            raise RuntimeError(f"请求失败: {last_error}") from last_error

print(fetch_json("https://jsonplaceholder.typicode.com/todos/1"))
检查点：必须设置 timeout；重试次数有上限；错误信息可读。

1.7 大模型接口：请求结构与模拟响应

真实供应商路径与计费不同。课堂用模拟响应理解 messages / choices 结构；有合法密钥的同学可选做真实调用。

def build_chat_request(user_text, model="demo-model"):
    return {
        "model": model,
        "messages": [
            {"role": "system", "content": "你是课程助教，用中文简明回答。"},
            {"role": "user", "content": user_text},
        ],
    }

def parse_chat_response(resp):
    try:
        return resp["choices"][0]["message"]["content"]
    except (KeyError, IndexError, TypeError) as exc:
        raise ValueError("响应结构不符合预期") from exc

def mock_chat(user_text):
    req = build_chat_request(user_text)
    fake = {
        "choices": [
            {"message": {"role": "assistant", "content": f"【模拟】已收到：{user_text[:20]}"}}
        ]
    }
    return req, parse_chat_response(fake)

req, answer = mock_chat("用一句话总结：本日采集了 60 本图书")
print("模型:", req["model"], "消息数:", len(req["messages"]))
print("回复:", answer)
检查点：能构造请求并解析回复；理解费用与不确定性边界。

1.8 综合：统一请求函数 + 模拟报告

import json
from pathlib import Path

def load_records():
    # 基础练习：不依赖付费 API
    path = Path("records_demo.json")
    if not path.exists():
        demo = [
            {"id": 1, "title": "Book A", "price": 12.0},
            {"id": 2, "title": "Book B", "price": 25.5},
        ]
        path.write_text(json.dumps(demo, ensure_ascii=False, indent=2), encoding="utf-8")
    return json.loads(path.read_text(encoding="utf-8"))

records = load_records()
avg_price = sum(r["price"] for r in records) / len(records)
summary = f"共 {len(records)} 条，均价 {avg_price:.2f}"
_, answer = mock_chat(summary)
print(summary)
print(answer)
检查点：无网络、无密钥也能跑通“读数据 → 汇总 → 模拟生成说明”。

1.9 常见错误

错误 1：把 API JSON 当成 HTML 去用 Beautiful Soup 解析。

错误 2：不设置 timeout。

错误 3：在代码里硬编码并打印密钥。

错误 4：无限重试，触发 429 后仍狂打接口。

错误 5：没有本地/模拟降级，断网就无法交作业。
