SOP4：函数与病例处理工具箱

代码越来越长以后，怎样让结构更清楚、更容易修改和复用？完成后你将得到「病例处理工具箱」。

1. 函数基础

def validate_patient(patient):
    if patient["time_in_hospital"] < 0:
        return False, "住院天数不能为负"
    return True, "ok"

def calculate_statistics(patients):
    n = len(patients)
    avg_stay = sum(p["time_in_hospital"] for p in patients) / n
    return {"count": n, "avg_stay": avg_stay}

2. 建议拆分的函数

  • validate_patient()

def filter_patients(patients, min_stay=7, min_inpatient=0, readmitted=None):
    result = []
    for p in patients:
        if p["time_in_hospital"] < min_stay:
            continue
        if p.get("number_inpatient", 0) < min_inpatient:
            continue
        if readmitted is not None and p["readmitted"] != readmitted:
            continue
        result.append(p)
    return result

3. 核心实验

把前面实验中的重复逻辑拆成函数，主程序只负责读取数据、调用函数、打印结果。

4. 进阶任务

实现通用筛选函数 filter_patients(patients, min_stay=..., min_inpatient=..., readmitted=...)，并用不同参数组合调用。
