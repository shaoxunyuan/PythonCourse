实验6：Python 文件与数据格式化

从三个学生的成绩保存与读取开始。完成本节后，能把程序结果写入磁盘，并在下次运行时读回、计算等级、用 f-string 规范输出。

本课目标 掌握 with open、r/w/a、TXT / CSV / JSON 读写与类型转换，以及 f-string 格式化输出
项目阶段 成绩写入与读回。用 TXT / CSV / JSON 完成「保存 → 读取 → 显示」
练习方式 本地运行代码并完成任务，再通过雨课堂填写实验记录

1. 练习

1.1 为什么需要文件

print 只是把内容显示在终端。程序一结束，屏幕上的结果就消失了。要把成绩留下，需要写入磁盘上的文件。

本节统一使用三名学生：张三 85（良好）、李四 72（及格）、王五 93（优秀）。等级规则：≥90 优秀，≥80 良好，≥60 及格，其余不及格。 
students = [
    {"name": "张三", "score": 85},
    {"name": "李四", "score": 72},
    {"name": "王五", "score": 93}
]
print(students)  # 只是显示，不等于已经保存到文件
检查点：能区分「屏幕输出」与「文件保存」：退出程序后，控制台显示不代表文件已写入。

1.2 准备三名学生数据

列表存放多名学生，字典保存每人的 name 与 score。后面的写入、读取都以这份数据为统一来源。

Step 1 / 建立数据
students = [
    {"name": "张三", "score": 85},
    {"name": "李四", "score": 72},
    {"name": "王五", "score": 93}
]
print(len(students))
print(students[0]["name"], students[0]["score"])
检查点：人数为 3；第一位是张三、85。

1.3 路径与 open / with

相对路径如 "students.txt"、"data/students.txt" 相对当前工作目录；绝对路径从盘符写起。路径错误是初学者常见问题。

Step 1 / open 的三个要点
# open(文件名, 模式, encoding=编码)
open("students.txt", "w", encoding="utf-8")
  • 文件名：操作哪个文件
  • 模式：如何操作（读 / 写 / 追加）
  • 编码：文本用什么编码（推荐 utf-8）
Step 2 / 推荐 with open
with open("students.txt", "w", encoding="utf-8") as f:
    f.write("张三,85\n")
# 代码块结束后，文件会自动关闭
检查点：with 管理文件使用范围，结束后自动关闭，比手动 close 更省心。

1.4 写入 TXT

write 写入字符串；文件不会自己换行，需要 \n。一行字符串里可以包含多个换行符。

Step 1 / 写入一行
with open("students.txt", "w", encoding="utf-8") as f:
    f.write("张三,85\n")
Step 2 / 用循环写入三人
with open("students.txt", "w", encoding="utf-8") as f:
    for student in students:
        f.write(f"{student['name']},{student['score']}\n")

生成的 students.txt 预期为：

张三,85
李四,72
王五,93
检查点：用编辑器打开 students.txt，应看到三行、逗号分隔。文本文件保存的是字符，不会自动理解「成绩」含义。

1.5 打开模式 r / w / a

  • r：读取；文件不存在会报错
  • w：写入；不存在则创建；已有内容会被清空覆盖
  • a：追加；在文件末尾继续写
想一想：对同一个 students.txt，用 "w" 再运行一遍写入循环，文件是 3 行还是 6 行？若改成 "a" 呢？先预测，再运行核对。
检查点：能说明 w 的覆盖风险；在教学目录中练习，不要去覆盖无关重要文件。

1.6 读取与解析

Step 1 / read() 读全部
with open("students.txt", "r", encoding="utf-8") as f:
    content = f.read()
print(content)
print(type(content))  # str
Step 2 / 逐行读取
with open("students.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())

strip() 去掉行首尾空白（含换行），不只是「去换行」。

Step 3 / 拆成姓名与整数成绩
line = "张三,85\n"
name, score_text = line.strip().split(",")
score = int(score_text)  # "85" → 85
print(name, score, type(score))
Step 4 / 读入后计算等级
def get_level(score):
    if score >= 90:
        return "优秀"
    elif score >= 80:
        return "良好"
    elif score >= 60:
        return "及格"
    else:
        return "不及格"

with open("students.txt", "r", encoding="utf-8") as f:
    for line in f:
        name, score_text = line.strip().split(",")
        score = int(score_text)
        print(name, score, get_level(score))
检查点：输出为张三 85 良好、李四 72 及格、王五 93 优秀。read() / 拆分得到的文本字段是 str，算等级前要 int()。

1.7 CSV 读写

CSV 是文本格式：标准化的列与记录，可用表格软件查看；它不等于 Excel 专有格式。带表头时，第一行是列名。

Step 1 / 写入 CSV
import csv

with open("students.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=["name", "score"])
    writer.writeheader()
    writer.writerows(students)

newline="" 可避免 Windows 上多余空行。

Step 2 / DictReader 读取
with open("students.csv", "r", encoding="utf-8", newline="") as f:
    for row in csv.DictReader(f):
        print(row)
        # 例如：{"name": "张三", "score": "85"}
        print(row["name"], int(row["score"]))
想一想：为什么读出来的 "85" 是字符串？"85" + "10" 与 85 + 10 结果有何不同？先预测再运行。
检查点：CSV 含 name,score 表头；DictReader 字段通常为 str，计算前用 int(row["score"])。

1.8 JSON 读写

JSON 适合表达列表、字典等结构化对象，不限于二维表。

Step 1 / dump 保存
import json

with open("students.json", "w", encoding="utf-8") as f:
    json.dump(students, f, ensure_ascii=False, indent=2)

ensure_ascii=False 保留中文；indent=2 便于阅读。注意：dump 写文件，dumps 得到字符串。

Step 2 / load 读回
with open("students.json", "r", encoding="utf-8") as f:
    data = json.load(f)

print(data[0]["name"])          # 张三
print(type(data[0]["score"]))   # <class 'int'>
检查点：json.load 可按 JSON 类型还原结构，数字常仍是 int，比手写 TXT 解析更省事。

1.9 格式选型与 f-string

  • TXT：自由文本、简单行记录；要自己解析
  • CSV：行列记录、表头明确；表格软件友好
  • JSON：嵌套结构、对象数据；结构可还原

格式化输出让结果更好读，不改变原始成绩。打印是呈现；保存到文件要另一步。

Step 1 / f-string
name = "张三"
score = 85
print(f"{name} 的 Python 成绩是 {score} 分")
print(f"{name}：{score} 分（{get_level(score)}）")
Step 2 / 显示精度与对齐
average = 83.3333
print(f"{average:.2f}")   # 83.33，只影响显示
print(f"{score:>5}")      # 宽度 5，右对齐
检查点：.2f 不修改 average 本身；文件格式与 Python 数据类型之间需要显式转换。

1.10 综合：成绩存取闭环

把写入 CSV、读回、算等级、f-string 输出连成一次完整运行。

Step 1 / 参考完整代码
import csv

students = [
    {"name": "张三", "score": 85},
    {"name": "李四", "score": 72},
    {"name": "王五", "score": 93}
]

def get_level(score):
    if score >= 90:
        return "优秀"
    elif score >= 80:
        return "良好"
    elif score >= 60:
        return "及格"
    else:
        return "不及格"

with open("students.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=["name", "score"])
    writer.writeheader()
    writer.writerows(students)

with open("students.csv", "r", encoding="utf-8", newline="") as f:
    for row in csv.DictReader(f):
        score = int(row["score"])
        print(f"{row['name']}：{score} 分（{get_level(score)}）")
检查点：依次输出张三：85 分（良好）、李四：72 分（及格）、王五：93 分（优秀）。

1.11 常见错误

错误 1：以为 print 已经保存了文件。

print(students)  # 只显示；要用 open + write / csv / json 才能落盘

错误 2：用 w 再次写入却期望「追加」。

# "w" 会清空原文件；末尾追加请用 "a"

错误 3：CSV 读入后直接当数字运算。

# score = row["score"] + 10   # 可能变成字符串拼接
score = int(row["score"]) + 10

错误 4：混淆 json.dump 与 json.dumps。

# dump → 写入文件对象；dumps → 得到字符串

错误 5：忘记 \n 或 Windows 下 CSV 未设 newline=""。
