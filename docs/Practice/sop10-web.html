SOP10：Python Web 应用与交互式分析平台

怎样让不会运行 Python 代码的人也能够使用程序？完成后你将得到「病例智能分析平台」Web 应用。

1. 从脚本到页面

  • 用户输入 → 程序处理 → 页面输出
  • 页面标题、文本、选择器、按钮、表格、图表、下载
  • 页面展示与数据处理逻辑分离，复用 SOP4～SOP9 的函数
# Streamlit 示意
import streamlit as st

st.title("病例智能分析平台")
uploaded = st.file_uploader("上传 CSV")
if st.button("开始分析") and uploaded is not None:
    st.write("在这里调用已有的分析函数")

2. 平台模块

  • 数据导入
  • 数据概览
  • 数据质量检查
  • 病例条件筛选
  • 统计分析
  • 数据可视化
  • AI 分析摘要

尽量复用已有模块，不要整份复制粘贴旧代码。

3. 核心实验

把前面功能整合到一个可在浏览器中操作的应用，至少覆盖上述模块中的主要流程。

4. 进阶任务

  • 参数联动、错误提示、结果下载
  • 更清晰的页面分区与操作引导
