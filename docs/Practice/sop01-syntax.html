SOP1：Python 语法元素与病例信息处理

真实世界中的一条病例信息，怎样变成 Python 可以处理的数据？完成后你将得到「病例信息处理器」：能输入、保存、计算并输出一条病例摘要。

1. 问题与字段

先使用这些字段：

  • patient_id
  • age
  • gender
  • time_in_hospital
  • num_medications
  • readmitted

2. 变量、赋值与基本类型

patient_id = 12345
age = "[70-80)"
gender = "Female"
time_in_hospital = 8
num_medications = 18
readmitted = "<30"
  • 标识符：变量名，如 time_in_hospital
  • 赋值：用 = 把值存进变量
  • 常见类型：int、float、str、bool
print(type(time_in_hospital))   # int
print(type(age))                # str
print(time_in_hospital + 1)     # 可以
# print(age + 1)                # 报错：类型不匹配
print(int("8"), str(12345), float("3.5"))

3. 运算与字符串

stay = 8
meds = 18
print(stay + 1, meds >= 10, gender == "Female")
print(age.startswith("["), "Female" in gender)
early = readmitted == "<30"
print(early and meds > 10)

4. 输入、输出与 f-string

patient_id = int(input("患者编号："))
age = input("年龄组：")
gender = input("性别：")
time_in_hospital = int(input("住院天数："))
num_medications = int(input("药物种数："))
readmitted = input("再入院标记（NO / >30 / <30）：")

flag = "是" if readmitted == "<30" else "否"
print(f"患者编号：{patient_id}")
print(f"年龄组：{age}")
print(f"本次住院：{time_in_hospital} 天")
print(f"使用药物：{num_medications} 种")
print(f"30天内再入院：{flag}")

5. 核心实验

  • 交互输入上述病例字段，并保存到变量
  • 对数值字段做类型转换，用 type() 检查
  • 做简单计算（例如住院天数 + 1）
  • 用 f-string 输出结构化病例摘要

6. 进阶任务

  • 住院天数、药物数量不能为负数
  • 输入必须能转成预期类型
  • readmitted 只能是 NO / >30 / <30

7. 作业

作业 1

编写程序：输入一条病例，输出完整摘要（含 30 天内再入院的中文“是/否”）。

作业 2

在作业 1 上增加合法性检查，并对非法输入给出明确提示。
