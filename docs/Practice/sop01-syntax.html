1. 练习

1.1 从一条病例开始

课程数据中的一行表示一次住院记录。本节先使用其中一条病例的部分字段：

  • patient_id：患者编号
  • gender：性别
  • age_group：年龄组（例如 [70-80)）
  • time_in_hospital：住院天数
  • num_medications：药物数量
  • number_inpatient：既往住院次数
  • readmitted：再入院标记（NO / >30 / <30）

核心问题：这些信息进入 Python 后，如何保存为变量、如何区分类型、如何完成计算与输出？

1.2 变量与赋值

变量用于保存数据。赋值语句用 = 将右侧的值存入左侧的变量名。

Step 1 / 创建病例变量
patient_id = 10001
gender = "Female"
age_group = "[70-80)"
time_in_hospital = 8
num_medications = 18
number_inpatient = 2
readmitted = "<30"
Step 2 / 打印变量
print(patient_id)
print(gender)
print(age_group)
print(time_in_hospital)
print(num_medications)
print(number_inpatient)
print(readmitted)
检查点：各变量输出与赋值一致。变量名拼写错误将导致 NameError。

1.3 基本数据类型

本节使用的基本类型：

  • int：整数，例如住院天数、药物数量
  • float：带小数的数值，例如日均药物数量
  • str：文本，例如性别、年龄组、再入院标记
  • bool：逻辑值 True / False
  • None：表示当前没有具体值
Step 1 / 观察 int 与 float
time_in_hospital = 8
num_medications = 18
average_medications_per_day = num_medications / time_in_hospital
print(average_medications_per_day)
print(type(time_in_hospital))
print(type(num_medications))
print(type(average_medications_per_day))
检查点：18 / 8 的结果为 2.25，类型为 <class 'float'>。两个操作数可以是 int，除法结果仍可为 float。
Step 2 / 观察 None
comment = None
print(comment)
print(type(comment))
检查点：None 的类型为 <class 'NoneType'>。None、"None"、0 三者含义不同。

1.4 type() 与类型转换

type() 用于查看变量类型。需要改变类型时，可使用 int()、float()、str()。

Step 1 / 查看病例变量类型
print(type(patient_id))
print(type(gender))
print(type(age_group))
print(type(time_in_hospital))
print(type(num_medications))
print(type(number_inpatient))
print(type(readmitted))
Step 2 / 类型转换
print(int("8"))
print(float("2.25"))
print(str(10001))
print(type(int("8")))
print(type(float("2.25")))
print(type(str(10001)))
检查点：编号、天数、药物数量、既往住院次数为 int；性别、年龄组、再入院标记为 str。

1.5 类型决定操作

数据“看起来像数字”并不等于它是数字。Python 依据类型决定运算含义。

Step 1 / 对比 "8"、8、8.0
a = "8"
b = 8
c = 8.0
print(type(a), type(b), type(c))
print(a + "1")
print(b + 1)
print(c + 1)
print(int(a) + 1)
print(str(b) + "1")
检查点："8" + "1" 得到 "81"（字符串拼接）；8 + 1 得到 9（数值加法）；8.0 + 1 得到 9.0。
Step 2 / 字符串与数字的加法差异
# print("住院时间：" + 8)   # 错误示例，去掉注释后可观察报错
print("住院时间：" + str(8))
print(f"住院时间：{8}")

1.6 算术运算与表达式

表达式根据已有变量计算得到新值。

Step 1 / 常用算术运算
time_in_hospital = 8
num_medications = 18
print(time_in_hospital + 1)
print(num_medications - 2)
print(num_medications * 2)
print(num_medications / time_in_hospital)
print(num_medications // time_in_hospital)
print(num_medications % time_in_hospital)
Step 2 / 日均药物数量
average_medications_per_day = num_medications / time_in_hospital
print(average_medications_per_day)
print(type(average_medications_per_day))
检查点：日均药物数量为 2.25，类型为 float。

1.7 比较与布尔值

比较表达式产生新的值，类型为 bool（True / False）。本节重点是理解比较结果，而不是展开复杂分支流程。

Step 1 / 数值比较
time_in_hospital = 8
long_stay = time_in_hospital >= 7
print(long_stay)
print(type(long_stay))
Step 2 / 字符串比较
readmitted = "<30"
early_readmit = readmitted == "<30"
print(early_readmit)
print(type(early_readmit))
Step 3 / 其他比较运算符
print(time_in_hospital > 7)
print(time_in_hospital < 7)
print(time_in_hospital <= 8)
print(time_in_hospital != 3)
print(readmitted == "NO")
检查点：long_stay 与 early_readmit 均为 True，类型均为 <class 'bool'>。此处“长住院”仅为课程编程示例规则。

1.8 基本逻辑表达式

and、or、not 用于组合 bool 值。本节只建立表达式，不做复杂病例筛选程序。

Step 1 / and / or / not
time_in_hospital = 8
number_inpatient = 2
readmitted = "<30"
long_stay = time_in_hospital >= 7
frequent_inpatient = number_inpatient >= 2
early_readmit = readmitted == "<30"

attention = long_stay and frequent_inpatient
print(attention)
print(long_stay or frequent_inpatient)
print(not early_readmit)
检查点：attention 为 True。逻辑运算的结果仍是 bool。

1.9 字符串基础操作

字符串除了保存文本，还可以使用方法进行基础处理。

Step 1 / strip / lower / upper / len
gender = " Female "
print(gender)
print(gender.strip())
print(gender.lower())
print(gender.upper())
print(len(gender))
print(len(gender.strip()))
Step 2 / replace（可选）
age_group = "[70-80)"
print(age_group.replace("-", "~"))
检查点：strip() 去除两端空白后，len 变小；lower() / upper() 只改变字母大小写。

1.10 输入、输出与 f-string

input() 用于读入数据，返回值类型为 str。数值计算前通常需要转换。print() 用于输出。f-string 用于把变量嵌入文本。

Step 1 / input 与类型转换
patient_id = int(input("患者编号："))
time_in_hospital = int(input("住院天数："))
print(type(patient_id), type(time_in_hospital))
print(f"患者编号：{patient_id}，住院 {time_in_hospital} 天")
Step 2 / 文本字段
gender = input("性别：").strip()
age_group = input("年龄组：").strip()
readmitted = input("再入院标记（NO / >30 / <30）：").strip()
print(gender, age_group, readmitted)
检查点：未转换时，input() 结果为 str；经 int() 后可用于数值计算。

1.11 综合：病例信息处理器 V0.1

将本节知识组合为单条病例摘要程序。以下为固定值版本，便于先核对输出；也可改为 input() 读入。

1.13 常见错误

错误 1：input() 返回字符串。

stay_days = input("住院天数：")
print(type(stay_days))  # str
# 若要计算，需先转换：
stay_days = int(stay_days)

错误 2：= 与 == 不同。

readmitted = "<30"      # 赋值
print(readmitted == "<30")  # 比较，结果为 bool

错误 3：字符串与数字不可直接相加。

# "住院时间：" + 8        # 错误
print("住院时间：" + str(8))
print(f"住院时间：{8}")

错误 4：True 与 "True" 不同。

print(type(True))     # bool
print(type("True"))   # str

错误 5：变量名必须一致。

stay_days = 8
# print(stay_day)   # NameError：少写了 s
