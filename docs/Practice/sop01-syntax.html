实验1：Python 语法元素与基本数据类型

用课程中的一条住院病例，把真实信息写成 Python 变量，并完成输入、计算、摘要输出与合法性检查。

本课目标 会用变量保存病例字段；分清 int / str / bool；能用 input 与 f-string 输出摘要；能检查输入是否合法
数据字段 patient_id、age、gender、time_in_hospital、num_medications、readmitted
与 diabetic_data.csv 含义一致
练习方式 按 1.1～1.7 顺序运行；做完练习再完成第 2 部分任务

1. 练习

1.1 变量与一条病例

一条住院记录里有很多字段。先用变量把其中 6 个常用字段保存下来：

  • patient_id：患者编号
  • age：年龄组（课程数据里类似 [70-80)）
  • gender：性别
  • time_in_hospital：本次住院天数
  • num_medications：药物种数
  • readmitted：再入院标记（NO / >30 / <30）

写法：左边是名字（标识符），右边是值，中间的 = 是赋值。

Step 1 / 创建一条病例的基本变量
patient_id = 12345
age = "[70-80)"
gender = "Female"
time_in_hospital = 8
num_medications = 18
readmitted = "<30"
Step 2 / 打印变量，确认已经保存成功
print(patient_id)
print(age)
print(gender)
print(time_in_hospital)
print(num_medications)
print(readmitted)
Step 3 / 用一句话同时打印多个字段
print(patient_id, gender, time_in_hospital, readmitted)
检查点：应能看到 12345、[70-80)、Female、8、18、<30。如果某变量名拼错，Python 会报 NameError。

1.2 查看类型 type()

不同类型能做的事情不同：整数可以加减，字符串适合保存文本。先用 type() 看清每个字段。

Step 1 / 查看各字段类型
print(type(patient_id))
print(type(age))
print(type(gender))
print(type(time_in_hospital))
print(type(num_medications))
print(type(readmitted))
检查点：编号、住院天数、药物种数应为 <class 'int'>；年龄组、性别、再入院标记应为 <class 'str'>。
Step 2 / 尝试类型转换
print(int("8"))
print(str(12345))
print(float("3.5"))
print(type(int("8")))
print(type(str(12345)))
Step 3 / 看清：input 读到的内容默认是字符串
x = "8"
print(type(x))      # str
y = int(x)
print(type(y))      # int
print(y + 1)        # 9
检查点：int("8") 得到整数后才能做 + 1。后面用 input() 读住院天数时，必须先 int(...)，否则无法可靠计算。

1.3 类型决定运算

任务 A 要求输出“若再住 1 天”的结果，这依赖整数加法。先确认哪些字段能算，哪些不能。

Step 1 / 整数可以做算术运算
print(time_in_hospital + 1)     # 若再住 1 天
print(num_medications * 2)
print(num_medications / 2)
print(num_medications // 2)     # 整除
print(num_medications % 2)      # 余数
Step 2 / 把“再住 1 天”存成新变量
stay_plus_one = time_in_hospital + 1
print(stay_plus_one)
print(type(stay_plus_one))
Step 3 / 字符串可以拼接，但不能直接加整数
print(age + " 年龄段")
print(gender + " / " + readmitted)
# print(age + 1)   # 去掉注释后会报错，可自行验证
检查点：time_in_hospital + 1 得到 9。若对 age 直接 + 1，应出现类型错误。任务 A 的“若再住1天”就是这里的加法。

1.4 比较与逻辑判断

任务里要把 readmitted == "<30" 转成中文“是/否”。比较结果是 bool（True / False）。

Step 1 / 比较运算
print(time_in_hospital >= 7)
print(num_medications > 10)
print(gender == "Female")
print(readmitted == "<30")
print(readmitted == "NO")
Step 2 / 把判断结果存成 bool 变量
long_stay = time_in_hospital >= 7
early_readmit = readmitted == "<30"
print(long_stay, type(long_stay))
print(early_readmit, type(early_readmit))
Step 3 / 转成中文“是/否”
if readmitted == "<30":
    flag = "是"
else:
    flag = "否"
print(flag)
Step 4 / 等价写法（三元表达式）
flag = "是" if readmitted == "<30" else "否"
print(flag)
Step 5 / 逻辑运算 and / or / not
print(long_stay and early_readmit)
print(long_stay or early_readmit)
print(not early_readmit)
检查点：当 readmitted = "<30" 时，flag 应为“是”；改为 NO 或 >30 后，应为“否”。

1.5 输入、输出与 f-string

任务要求交互输入。注意：input() 返回的是字符串；需要计算的数字必须先转换。

Step 1 / 用 f-string 输出固定值
patient_id = 12345
age = "[70-80)"
gender = "Female"
time_in_hospital = 8
num_medications = 18
flag = "是"
stay_plus_one = time_in_hospital + 1

print(f"患者编号：{patient_id}")
print(f"年龄组：{age}")
print(f"性别：{gender}")
print(f"本次住院：{time_in_hospital} 天")
print(f"若再住1天：{stay_plus_one} 天")
print(f"使用药物：{num_medications} 种")
print(f"30天内再入院：{flag}")
检查点：输出格式应与任务 A 的示例一致（字段齐全，含“若再住1天”）。
Step 2 / 用 input 读入两个数值字段
patient_id = int(input("患者编号："))
time_in_hospital = int(input("住院天数："))
print(type(patient_id), type(time_in_hospital))
print(f"患者编号：{patient_id}，住院 {time_in_hospital} 天")
print(f"若再住1天：{time_in_hospital + 1} 天")
Step 3 / 文本字段保持字符串即可
age = input("年龄组（如 [70-80)）：")
gender = input("性别：")
readmitted = input("再入院标记（NO / >30 / <30）：")
print(type(age), type(gender), type(readmitted))
print(age, gender, readmitted)
检查点：数值字段转换后类型为 int；文本字段为 str。若输入字母却强制 int(...)，会报 ValueError（下一节处理）。

1.6 综合：输入一条病例并输出摘要

把前面内容串起来，形成与任务 A 对应的完整流程：读入 6 个字段 → 转换 → 判断 → 计算“再住 1 天” → 输出摘要。

Step 1 / 完整示例（对应任务 A）
patient_id = int(input("患者编号："))
age = input("年龄组（如 [70-80)）：")
gender = input("性别：")
time_in_hospital = int(input("住院天数："))
num_medications = int(input("药物种数："))
readmitted = input("再入院标记（NO / >30 / <30）：")

print(type(patient_id), type(age), type(time_in_hospital), type(num_medications))

stay_plus_one = time_in_hospital + 1
flag = "是" if readmitted == "<30" else "否"

print(f"患者编号：{patient_id}")
print(f"年龄组：{age}")
print(f"性别：{gender}")
print(f"本次住院：{time_in_hospital} 天")
print(f"若再住1天：{stay_plus_one} 天")
print(f"使用药物：{num_medications} 种")
print(f"30天内再入院：{flag}")
Step 2 / 建议自测输入
12345
[70-80)
Female
8
18
<30
检查点：摘要应包含性别与“若再住1天：9 天”；再入院显示“是”。把最后一行改成 NO 再跑一次，应显示“否”。

1.7 输入合法性检查

任务 B 要求：非法输入要提示原因，并重新输入直到合法。下面分别练习三类检查。

Step 1 / 检查非负数（住院天数、药物种数）
time_in_hospital = int(input("住院天数："))
while time_in_hospital < 0:
    print("住院天数不能为负数")
    time_in_hospital = int(input("请重新输入住院天数："))
print("合法住院天数：", time_in_hospital)
Step 2 / 检查整数转换是否成功
while True:
    text = input("患者编号：")
    try:
        patient_id = int(text)
        break
    except ValueError:
        print("患者编号必须是整数，请重新输入")
print("合法患者编号：", patient_id, type(patient_id))
Step 3 / 检查 readmitted 只能是三种取值
allowed = {"NO", ">30", "<30"}
readmitted = input("再入院标记（NO / >30 / <30）：")
while readmitted not in allowed:
    print("再入院标记只能是 NO / >30 / <30")
    readmitted = input("请重新输入再入院标记：")
print("合法标记：", readmitted)
Step 4 / 把检查拼进一条完整流程（对应任务 B 骨架）
allowed = {"NO", ">30", "<30"}

while True:
    try:
        patient_id = int(input("患者编号："))
        break
    except ValueError:
        print("患者编号必须是整数，请重新输入")

age = input("年龄组（如 [70-80)）：")
gender = input("性别：")

while True:
    try:
        time_in_hospital = int(input("住院天数："))
        if time_in_hospital < 0:
            print("住院天数不能为负数")
            continue
        break
    except ValueError:
        print("住院天数必须是整数，请重新输入")

while True:
    try:
        num_medications = int(input("药物种数："))
        if num_medications < 0:
            print("药物种数不能为负数")
            continue
        break
    except ValueError:
        print("药物种数必须是整数，请重新输入")

readmitted = input("再入院标记（NO / >30 / <30）：")
while readmitted not in allowed:
    print("再入院标记只能是 NO / >30 / <30")
    readmitted = input("请重新输入再入院标记：")

stay_plus_one = time_in_hospital + 1
flag = "是" if readmitted == "<30" else "否"

print(f"患者编号：{patient_id}")
print(f"年龄组：{age}")
print(f"性别：{gender}")
print(f"本次住院：{time_in_hospital} 天")
print(f"若再住1天：{stay_plus_one} 天")
print(f"使用药物：{num_medications} 种")
print(f"30天内再入院：{flag}")
Step 5 / 建议故意输入错误，观察提示
  • 住院天数输入 -1，应提示不能为负并要求重输
  • 患者编号输入 abc，应提示必须是整数
  • 再入院标记输入 yes，应提示只能是三种合法取值
检查点：错误输入不会直接崩溃结束；修正后仍能输出完整摘要。这正是任务 B 的核心要求。

2. 任务

在完成第 1 部分练习后，基于糖尿病住院病例字段独立完成下列任务。字段含义与 diabetic_data.csv 一致。

2.1 任务 A：病例摘要程序

对应练习 1.1～1.6。编写一个可运行的 .py 程序。

输入（用 input 依次读入）：

  • patient_id：患者编号（整数）
  • age：年龄组（文本，例如 [70-80)）
  • gender：性别（文本，例如 Female / Male）
  • time_in_hospital：住院天数（整数）
  • num_medications：药物种数（整数）
  • readmitted：再入院标记（文本，取值为 NO / >30 / <30）

处理：

  • 编号、住院天数、药物种数必须转为 int
  • 至少用 type() 打印一次关键变量类型
  • 若 readmitted == "<30"，摘要中显示“是”，否则显示“否”
  • 计算并输出：若再住 1 天，总住院天数是多少（time_in_hospital + 1）

输出格式示例：

患者编号：12345
年龄组：[70-80)
性别：Female
本次住院：8 天
若再住1天：9 天
使用药物：18 种
30天内再入院：是

2.2 任务 B：合法性检查

对应练习 1.7。在任务 A 基础上增加输入检查。全部字段合法后，再输出摘要。

检查规则：

  • time_in_hospital 不能为负数
  • num_medications 不能为负数
  • patient_id、time_in_hospital、num_medications 必须能转为整数；无法转换时给出提示
  • readmitted 只能是 NO、>30、<30 三者之一

交互要求：

  • 非法时打印明确原因（例如：“住院天数不能为负数”）
  • 对该字段重新输入，直到合法为止
  • 全部合法后，输出与任务 A 相同格式的摘要
提交建议：两个可运行的 .py 文件（或一个文件中清晰分出任务 A / 任务 B）；可附一段输入示例与对应输出。
