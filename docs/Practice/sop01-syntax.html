实验1：Python 语法元素与基本数据类型

用课程中的一条住院病例，把真实信息写成 Python 变量，并完成输入、计算与摘要输出。 每一小段代码尽量短，方便「复制 → 运行 → 核对输出」。

本课目标会用变量保存病例字段，分清 int / str / bool，能用 input() 与 f-string 输出病例摘要
数据字段patient_id、age、gender、time_in_hospital、num_medications、readmitted
练习方式按步骤在本地 Python 环境逐段运行；先完成第 1 部分练习，再做第 2 部分任务

1. 练习

下面按知识点拆成若干小步。建议每完成一步，先看输出是否符合检查点，再进入下一步。

1.1 变量与一条病例

先把一条病例写成若干变量。左边是名字（标识符），右边是值，中间的 = 是赋值。

Step 1 / 创建一条病例的基本变量
patient_id = 12345
age = "[70-80)"
gender = "Female"
time_in_hospital = 8
num_medications = 18
readmitted = "<30"
Step 2 / 打印变量，确认已经保存成功
print(patient_id)
print(age)
print(gender)
print(time_in_hospital)
print(num_medications)
print(readmitted)
检查点：应依次看到 12345、[70-80)、Female、8、18、<30。

1.2 查看类型 type()

不同类型的值，能做的运算不同。先用 type() 看清每个字段属于什么类型。

Step 1 / 查看各字段类型
print(type(patient_id))
print(type(age))
print(type(gender))
print(type(time_in_hospital))
print(type(num_medications))
print(type(readmitted))
检查点：编号、住院天数、药物种数应为 <class 'int'>；年龄组、性别、再入院标记应为 <class 'str'>。
Step 2 / 做类型转换
print(int("8"))
print(str(12345))
print(float("3.5"))
检查点：分别得到整数 8、字符串 '12345'、浮点数 3.5。

1.3 类型决定运算

同样是“加 1”，对整数和字符串结果完全不同：一个可以算，一个会报错。

Step 1 / 整数可以做算术运算
print(time_in_hospital + 1)
print(num_medications * 2)
print(num_medications / 2)
Step 2 / 字符串可以拼接，但不能直接加整数
print(age + " 年龄段")
print(gender + " / " + readmitted)
# print(age + 1)   # 去掉注释后会报错，可自行验证
检查点：time_in_hospital + 1 得到 9；age + " 年龄段" 得到文本拼接结果。若对字符串直接 + 1，应出现类型错误。

1.4 比较与逻辑判断

比较运算的结果是 bool（True / False），常用于后续筛选病例。

Step 1 / 比较运算
print(time_in_hospital >= 7)
print(num_medications > 10)
print(gender == "Female")
print(readmitted == "<30")
Step 2 / 逻辑运算 and / or / not
long_stay = time_in_hospital >= 7
early_readmit = readmitted == "<30"
print(long_stay and early_readmit)
print(long_stay or early_readmit)
print(not early_readmit)
检查点：对本例数据，time_in_hospital >= 7 与 readmitted == "<30" 均为 True，因此 and 结果也为 True。

1.5 输入、输出与 f-string

input() 读到的内容默认是字符串；需要计算的数字要先 int() / float()。f-string 适合把变量嵌进输出文本。

Step 1 / 先练习固定值的 f-string 输出
patient_id = 12345
time_in_hospital = 8
print(f"患者编号：{patient_id}")
print(f"本次住院：{time_in_hospital} 天")
Step 2 / 用 input 读入，并转换为整数
patient_id = int(input("患者编号："))
time_in_hospital = int(input("住院天数："))
print(type(patient_id), type(time_in_hospital))
print(f"患者编号：{patient_id}，住院 {time_in_hospital} 天")
检查点：输入数字后，type(...) 应显示 <class 'int'>；输出中应出现你刚输入的编号与天数。

1.6 综合：输入一条病例并输出摘要

把前面知识点串起来：读入 6 个字段 → 转换类型 → 判断是否 30 天内再入院 → 输出摘要。

Step 1 / 完整示例（可直接运行）
patient_id = int(input("患者编号："))
age = input("年龄组（如 [70-80)）：")
gender = input("性别：")
time_in_hospital = int(input("住院天数："))
num_medications = int(input("药物种数："))
readmitted = input("再入院标记（NO / >30 / <30）：")

print(type(patient_id), type(age), type(time_in_hospital))

flag = "是" if readmitted == "<30" else "否"

print(f"患者编号：{patient_id}")
print(f"年龄组：{age}")
print(f"性别：{gender}")
print(f"本次住院：{time_in_hospital} 天")
print(f"使用药物：{num_medications} 种")
print(f"30天内再入院：{flag}")
Step 2 / 建议自测输入
12345
[70-80)
Female
8
18
<30
检查点：摘要中应出现“30天内再入院：是”；若最后一行输入 NO，则应显示“否”。

2. 任务

在完成第 1 部分练习后，基于糖尿病住院病例字段独立完成下列任务。字段含义与课程数据 diabetic_data.csv 一致。

2.1 任务 A：病例摘要程序

编写一个可运行的 .py 程序。

输入（用 input 依次读入）：

  • patient_id：患者编号（整数）
  • age：年龄组（文本，例如 [70-80)）
  • gender：性别（文本，例如 Female / Male）
  • time_in_hospital：住院天数（整数）
  • num_medications：药物种数（整数）
  • readmitted：再入院标记（文本，取值为 NO / >30 / <30）

处理：

  • 编号、住院天数、药物种数必须转为 int
  • 至少用 type() 打印一次关键变量类型
  • 若 readmitted == "<30"，摘要中显示“是”，否则显示“否”
  • 额外计算并输出：若再住 1 天，总住院天数是多少（time_in_hospital + 1）

输出格式示例：

患者编号：12345
年龄组：[70-80)
性别：Female
本次住院：8 天
若再住1天：9 天
使用药物：18 种
30天内再入院：是

2.2 任务 B：合法性检查

在任务 A 基础上增加输入检查。全部字段合法后，再输出摘要。

检查规则：

  • time_in_hospital 不能为负数
  • num_medications 不能为负数
  • patient_id、time_in_hospital、num_medications 必须能转为整数；无法转换时给出提示
  • readmitted 只能是 NO、>30、<30 三者之一

交互要求：

  • 非法时打印明确原因（例如：“住院天数不能为负数”）
  • 对该字段重新输入，直到合法为止
  • 全部合法后，输出与任务 A 相同格式的摘要
提交建议：两个可运行的 .py 文件（或一个文件中清晰分出任务 A / 任务 B）；可附一段输入示例与对应输出。
