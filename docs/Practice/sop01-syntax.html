实验1：Python 语法元素与基本数据类型

真实世界中的一条病例信息，怎样变成 Python 可以处理的数据？完成后得到「病例信息处理器」：能表示并处理一条病例。

一、本次要解决的问题

课程数据里有十几万条住院记录。今天先只看一条病例：

  • 它有哪些信息？
  • 这些信息在 Python 里分别是什么类型？
  • 怎样读入、计算，并输出一份可读的病例摘要？

二、项目进度

  • 上一阶段：已认识课程数据（SOP0）
  • 本次增加：用变量保存一条病例，并完成输入、计算、输出
  • 完成后升级：单病例信息处理

三、本次知识点

  • 标识符、变量、赋值
  • int / float / str / bool
  • type() 与类型转换
  • 算术运算、比较运算、逻辑运算
  • 字符串基本操作
  • print()、input()、f-string

四、讲授内容

1. 一条病例怎样变成变量

patient_id = 12345
age = "[70-80)"
gender = "Female"
time_in_hospital = 8
num_medications = 18
readmitted = "<30"
  • 变量：存放数据的名字
  • 标识符：变量名本身
  • 值：真正保存的内容
  • 赋值语句：用 = 把值存进变量

2. 类型决定能做什么

print(type(time_in_hospital))  # <class 'int'>
print(type(age))               # <class 'str'>
print(time_in_hospital + 1)    # 可以
# print(age + 1)               # 报错：字符串不能直接加整数
print(int("8"), str(12345))

3. 运算与判断

print(time_in_hospital >= 7)
print(gender == "Female")
print(readmitted == "<30" and num_medications > 10)

4. 输入、输出与 f-string

patient_id = int(input("患者编号："))
age = input("年龄组：")
time_in_hospital = int(input("住院天数："))
print(f"患者编号：{patient_id}，住院 {time_in_hospital} 天")

五、跟随演示

演示流程：输入病例信息 → 简单计算 → 输出摘要。

patient_id = int(input("患者编号："))
age = input("年龄组（如 [70-80)）：")
gender = input("性别：")
time_in_hospital = int(input("住院天数："))
num_medications = int(input("药物种数："))
readmitted = input("再入院标记（NO / >30 / <30）：")

flag = "是" if readmitted == "<30" else "否"

print(f"患者编号：{patient_id}")
print(f"年龄组：{age}")
print(f"本次住院：{time_in_hospital} 天")
print(f"使用药物：{num_medications} 种")
print(f"30天内再入院：{flag}")

六、核心实验任务

任务 1

  • 题目：交互输入一条病例的 patient_id、age、gender、time_in_hospital、num_medications、readmitted
  • 要求：数值字段做类型转换，并保存到变量
  • 预期结果：程序能正确读入并保存这些字段

任务 2

  • 题目：对关键变量使用 type() 检查类型
  • 要求：确认数值为 int，文本为 str
  • 预期结果：屏幕打印出各变量类型

任务 3

  • 题目：做简单计算，并用 f-string 输出病例摘要
  • 要求：摘要至少包含编号、年龄组、住院天数、药物种数、是否 30 天内再入院
  • 预期结果：输出格式类似：
患者编号：12345
年龄组：[70-80)
本次住院：8 天
使用药物：18 种
30天内再入院：是

七、进阶任务

  • 住院天数不能为负数
  • 药物数量不能为负数
  • 输入值必须符合预期类型
  • readmitted 只能是 NO / >30 / <30

不合法时给出提示，并要求重新输入。

八、本次项目结果

    ↓

    ↓
简单计算
    ↓
格式化输出病例摘要

完成后：可以表示和处理一条结构化病例的基本信息。
