Practice

  • SOP0：认识课程数据
    糖尿病住院病例数据说明，以及字段如何对应到 Python 中的变量与类型。
  • SOP1：Python 语法元素与病例信息处理
    用一条病例练习变量、类型、运算、输入输出与格式化摘要。
  • SOP2：Python 数据结构与病例组织
    用 list / dict 组织多名患者与多条病例，完成增删改查与统计。
  • SOP3：程序控制结构与病例规则筛选
    用条件与循环批量判断病例，完成筛选、计数与比例计算。
  • SOP4：函数与病例处理工具箱
    把长脚本拆成可复用函数，主程序只负责调用与组合。
  • SOP5：动态函数与可配置病例规则
    把规则做成函数对象与规则字典，运行时选择或组合规则。
  • SOP6：文件操作与数据格式转换
    在 CSV / JSON / TXT 之间读写转换，并处理常见文件异常。
  • SOP7：真实病例数据读取、检查与清洗
    读取十万条真实数据，完成质量检查并生成质量报告。
  • SOP8：pandas 综合数据处理与病例分析
    用 pandas 做分组统计与可视化，导出表格与图表。
  • SOP9：网络请求、大模型 API 与智能报告
    先用 Python 完成统计，再调用大模型生成自然语言摘要。
  • SOP10：Python Web 应用与交互式分析平台
    把已有模块接入 Web 页面，形成可交互的分析平台。
  • SOP11：完整项目集成、测试与交付
    模块化整合学期成果，完成可运行、可解释的最终平台。
