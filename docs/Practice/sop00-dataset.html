SOP0：认识课程数据

开始写代码之前，先弄清：整个学期在处理什么数据、数据有多大、一行代表什么。

1. 数据文件

课程数据在 data/ 目录：

  • diabetic_data.csv：主数据，住院记录
  • IDS_mapping.csv：编码字段说明

2. 数据维度

diabetic_data.csv 实际维度：

  • 101,766 行 × 50 列
  • 101,766 条住院记录
  • 50 个字段
  • 不同 patient_nbr：71,518

3. 一行代表什么

101,766 行并不代表 101,766 名患者。
一行表示一次住院记录（encounter），不是一名唯一患者。
  • patient_nbr：患者编号
  • encounter_id：一次具体住院记录编号

可能存在多次住院
        ↓

4. 数据主要包含什么

50 个字段大致分为：

  • A. 患者基本信息：race、gender、age
  • B. 入院相关信息：admission_type_id、discharge_disposition_id、admission_source_id、time_in_hospital
  • C. 医疗过程相关数据：num_lab_procedures、num_procedures、num_medications、number_outpatient、number_emergency、number_inpatient
  • D. 诊断信息：diag_1、diag_2、diag_3
  • E. 检验相关信息：max_glu_serum、A1Cresult
  • F. 糖尿病相关药物信息：如 metformin、glipizide、glyburide、pioglitazone、insulin
  • G. 治疗变化信息：change、diabetesMed
  • H. 再入院信息：readmitted

readmitted 取值与条数：

  • NO：54,864
  • >30：35,545
  • <30：11,357

本课程不以机器学习预测为主要教学目标。readmitted 用于练习条件判断、数据筛选、循环、函数、统计、分组、可视化、文件输出与综合分析。

5. IDS_mapping.csv

辅助编码说明文件，约 67 行 × 2 列。用于解释：

  • admission_type_id
  • discharge_disposition_id
  • admission_source_id

例如 admission_type_id = 1 对应 Emergency。

6. 这份数据怎么用

这份数据不是医学诊断教材，也不是复杂机器学习模型的训练目标。它是整门课的统一数据主线：从一条病例逐步过渡到完整的 101,766 条记录。

一条病例
    ↓
多条病例
    ↓
列表和字典
    ↓
条件判断 / 循环 / 函数
    ↓
CSV / JSON / TXT
    ↓
完整真实数据与清洗
    ↓
pandas / 统计与可视化
    ↓
大模型 API
    ↓
Web 平台
本数据仅用于 Python 编程、数据处理和软件开发教学。
病例筛选规则、统计结果以及大模型生成内容，均不用于临床诊断、治疗决策或真实医疗活动。
