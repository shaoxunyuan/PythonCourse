SOP0：认识课程数据

认识糖尿病住院病例数据：文件内容、一行含义，以及字段如何写成 Python 变量。

1. 数据文件

课程使用两份数据：

  • data/diabetic_data.csv：主数据，住院记录
  • data/IDS_mapping.csv：医院编码字段的文字说明

CSV 是用逗号分隔的表格文本。第一行是列名，后面每一行是一条记录。

2. 数据长什么样

diabetic_data.csv：101,766 行 × 50 列，不同 patient_nbr 约 71,518。下面是关键字段的前 5 行。

3. 一行代表什么

一行 = 一次住院记录（encounter），不是一名唯一患者。
101,766 行 ≠ 101,766 名患者。
  • patient_nbr：患者编号
  • encounter_id：本次住院编号
患者 patient_nbr
        ↓
可能多次住院
        ↓
encounter_id 1 / 2 / 3 …

4. 数据包含哪些信息

  • 患者基本信息：race、gender、age、weight
  • 入院信息：admission_type_id、admission_source_id、discharge_disposition_id、time_in_hospital
  • 住院过程：num_lab_procedures、num_procedures、num_medications
  • 既往就诊：number_outpatient、number_emergency、number_inpatient
  • 诊断与检验：diag_1～diag_3、max_glu_serum、A1Cresult
  • 药物与治疗变化：如 insulin、metformin、change、diabetesMed
  • 再次入院：readmitted（NO / >30 / <30）

readmitted 分布：NO 54864，>30 35545，<30 11357。原始数据中常见 ? 表示缺失。
