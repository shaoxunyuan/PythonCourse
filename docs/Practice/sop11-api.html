1.1 HTML 网页 vs API JSON

浏览网页常得到 HTML；调用数据接口更常见 JSON。本章重点是结构化 API，不是用 Beautiful Soup 解析整页 HTML。

检查点：能用一句话区分“页面文档”与“接口数据”。

1.2 第一次 GET：状态码与字段

下面使用公共教学接口。若网络不可用，请改用本地模拟 JSON。

import requests

url = "https://jsonplaceholder.typicode.com/todos/1"
response = requests.get(url, timeout=10)
response.raise_for_status()
data = response.json()
print("编号:", data["id"])
print("任务:", data["title"])
print("完成:", data["completed"])
离线备份：本地文件 todo_1.json
import json
from pathlib import Path
data = json.loads(Path("todo_1.json").read_text(encoding="utf-8"))
print(data["id"], data["title"], data["completed"])
检查点：在线或离线都能读出 id / title / completed。

1.3 GET 参数与 POST JSON

import requests

r = requests.get(
    "https://jsonplaceholder.typicode.com/posts",
    params={"userId": 1},
    timeout=10,
)
r.raise_for_status()
posts = r.json()
print("返回条数:", len(posts))
print("第一条标题:", posts[0]["title"])

r2 = requests.post(
    "https://jsonplaceholder.typicode.com/posts",
    json={"title": "demo", "body": "hello", "userId": 1},
    timeout=10,
)
print("POST 状态码:", r2.status_code)
print(r2.json())
检查点：理解 params 与 json= 的用途；失败时查看状态码。

1.4 嵌套结构与缺字段

payload = {
    "data": {
        "items": [
            {"id": 1, "name": "alpha"},
            {"id": 2}
        ]
    }
}
for item in payload["data"]["items"]:
    name = item.get("name")
    if name is None:
        print(item["id"], "缺少 name")
    else:
        print(item["id"], name)
检查点：用 .get 处理缺字段。

1.5 超时、HTTP 错误与有限重试

import time
import requests

def fetch_json(url, retries=2, timeout=10):
    last_error = None
    for attempt in range(retries + 1):
        try:
            r = requests.get(url, timeout=timeout)
            if r.status_code in (401, 429) or r.status_code >= 500:
                raise requests.HTTPError(f"HTTP {r.status_code}", response=r)
            r.raise_for_status()
            return r.json()
        except (requests.Timeout, requests.HTTPError, requests.RequestException) as exc:
            last_error = exc
            if attempt < retries:
                time.sleep(0.5)
                continue
            raise
    raise RuntimeError(last_error)

print("请在可联网环境调用 fetch_json；失败时应看到清晰错误")
检查点：设置 timeout；对 401/429/5xx 有可读处理；重试有上限。

1.7 大模型调用：结构与模拟响应

def build_chat_request(user_text, model="demo-model"):
    return {
        "model": model,
        "messages": [
            {"role": "system", "content": "你是课程助教，回答简明。"},
            {"role": "user", "content": user_text},
        ]
    }

def parse_chat_response(resp):
    try:
        return resp["choices"][0]["message"]["content"]
    except (KeyError, IndexError, TypeError) as exc:
        raise ValueError("响应结构不符合预期") from exc

fake_response = {
    "choices": [
        {"message": {"role": "assistant", "content": "这是模拟回复：病例数已汇总。"}}
    ]
}
req = build_chat_request("请用一句话总结病例数")
print("请求要点:", req["model"], len(req["messages"]))
print("模拟回复:", parse_chat_response(fake_response))
检查点：能构造请求消息并解析回复文本。

1.8 常见错误

错误 2：把 HTML 当 JSON 解析。

错误 3：泄露 API Key。

错误 4：无限重试。
