1. 练习

1.1 认识表格：行与列

本课使用教学模拟病例表：每一行是一条病例记录，每一列是一个字段（如组别、住院天数）。

import pandas as pd

records = pd.DataFrame({
    "case_id": ["C001", "C002", "C003", "C004"],
    "group": ["A", "A", "B", "B"],
    "stay_days": [5, 7, 4, 8],
    "age": [45, 51, 38, 60]
})
print(records)
print("行数:", len(records), "列名:", list(records.columns))
检查点：能说明一行代表一条记录，列名是字段名。

1.3 选列、筛选与排序

import pandas as pd
df = pd.DataFrame({
    "group": ["A", "A", "B", "B"],
    "stay_days": [5, 7, 4, 8],
    "age": [45, 51, 38, 60]
})
print(df["stay_days"])
print(df.loc[df["group"] == "A", ["group", "stay_days"]])
print(df[df["age"] >= 50])
print(df.sort_values("stay_days", ascending=False))
多个条件请用括号：df[(df["age"] >= 40) & (df["group"] == "A")]。
检查点：能按条件筛选，并理解 loc 按标签选取。

1.4 缺失与重复

import pandas as pd
df = pd.DataFrame({
    "case_id": ["C001", "C002", "C002", "C003"],
    "stay_days": [5, None, 7, 4]
})
print("缺失数:\n", df.isna().sum())
print("重复 case_id 数:", df["case_id"].duplicated().sum())
print(df.drop_duplicates("case_id"))
print(df.dropna(subset=["stay_days"]))
检查点：能解释删除、填补、保留分别在什么情况下更合适，并记录自己的选择。

1.5 类型转换 to_numeric

import pandas as pd
s = pd.Series(["5", "7", "x", "8"])
num = pd.to_numeric(s, errors="coerce")
print(num)
print("转换失败变成缺失的个数:", num.isna().sum())
检查点：errors="coerce" 会把无法转换的值变成缺失，必须复查。

1.6 新增列与简单统计

import pandas as pd
df = pd.DataFrame({"stay_days": [5, 7, 4, 8]})
df["long_stay"] = df["stay_days"] >= 7
print(df)
print("平均住院天数:", df["stay_days"].mean())
检查点：新增列不覆盖原列；统计结果可用手工验算。

1.7 groupby 汇总

import pandas as pd

records = pd.DataFrame({
    "group": ["A", "A", "B", "B"],
    "stay_days": [5, 7, 4, 8]
})
summary = records.groupby("group", as_index=False).agg(
    sample_count=("stay_days", "size"),
    mean_stay=("stay_days", "mean")
)
print(summary)

size 计行数（含缺失）；count 通常不计该列缺失。教学字段须有明确含义。

检查点：得到每组样本数与平均住院天数。

1.8 保存清洗结果

import pandas as pd
clean = pd.DataFrame({
    "case_id": ["C001", "C003"],
    "group": ["A", "B"],
    "stay_days": [5, 4]
})
summary = pd.DataFrame({"group": ["A", "B"], "sample_count": [1, 1], "mean_stay": [5.0, 4.0]})
clean.to_csv("cases_clean.csv", index=False, encoding="utf-8-sig")
summary.to_csv("cases_summary.csv", index=False, encoding="utf-8-sig")
print("已写出 cases_clean.csv 与 cases_summary.csv")
检查点：任何删除/填补都要在说明里写清规则；输出使用 UTF-8（或 utf-8-sig）。

1.9 常见错误

错误 1：链式筛选忘记括号，条件优先级出错。

错误 2：把 to_numeric 失败产生的缺失当成“本来就没数据”而不复查。

错误 3：去重时未指定子集，误删不同病例。

错误 4：混淆 size 与 count。

错误 5：保存 CSV 未说明编码，Excel 打开中文乱码。
