1. 练习

1.1 列表加法 vs 数组加法

先预测结果，再运行。列表的 + 是拼接；NumPy 数组的 + 是逐元素相加。

import numpy as np

a_list = [1, 2, 3]
b_list = [10, 20, 30]
print("列表相加:", a_list + b_list)

a = np.array([1, 2, 3])
b = np.array([10, 20, 30])
print("数组相加:", a + b)
想一想：若希望列表也做逐元素相加，要用循环或推导式；数组则直接写 a + b。
检查点：列表得到 [1, 2, 3, 10, 20, 30]；数组得到 [11 22 33]。

1.2 创建数组与 shape / dtype / ndim

import numpy as np

x = np.array([1.5, 2.0, 3.5])
m = np.array([
    [86, 90, 88],
    [72, 79, 81],
    [95, 93, 97]
])
z = np.zeros((2, 3))
r = np.arange(0, 10, 2)

print(x.shape, x.ndim, x.dtype)
print(m.shape, m.ndim, m.dtype)
print(z)
print(r)
检查点：一维测验向量 ndim=1；成绩矩阵形状为 (3, 3)，ndim=2。

1.3 索引与切片

import numpy as np
m = np.array([
    [86, 90, 88],
    [72, 79, 81],
    [95, 93, 97]
])
print("单个元素 m[0, 1] =", m[0, 1])
print("第 1 行:", m[0])
print("第 2 列:", m[:, 1])
print("子矩阵:\n", m[0:2, 1:3])
检查点：能取出单个元素、整行、整列与子矩阵，索引从 0 开始。

1.4 向量化运算与单位换算

数组运算默认逐元素进行，不必手写三重循环。

import numpy as np
cm = np.array([160, 175, 182], dtype=float)
meters = cm / 100
print(meters)
print(meters * 2)
检查点：得到米制身高；乘以 2 仍是逐元素缩放。

1.5 布尔索引

import numpy as np
values = np.array([6, 12, 9, 15, 3])
mask = values >= 10
print("掩码:", mask)
print("筛选结果:", values[mask])
检查点：掩码是布尔数组；用它取子集得到满足条件的元素。

1.6 按轴统计

axis=1 沿列方向聚合，得到每一行的统计；axis=0 沿行方向聚合，得到每一列的统计。

import numpy as np

scores = np.array([
    [86, 90, 88],
    [72, 79, 81],
    [95, 93, 97]
])
print("形状:", scores.shape)
print("每名学生的平均分:", scores.mean(axis=1))
print("每次测试的平均分:", scores.mean(axis=0))
print("各学生达标次数:", (scores >= 80).sum(axis=1))

预期（近似）：学生均分约 [88. 77.333 95. ]；测验均分约 [84.333 87.333 88.667]；达标次数 [3 1 3]。

检查点：能解释 axis 方向，并用手工验算其中一行/一列。

1.7 广播与形状错误

import numpy as np
row = np.array([1, 2, 3])
col = np.array([[10], [20], [30]])
print(row + col)  # (3,) 与 (3,1) 可广播

a = np.ones((2, 3))
b = np.ones((2, 4))
try:
    print(a + b)
except ValueError as e:
    print("形状不兼容:", e)
检查点：不是任意数组都能相加；形状不满足广播规则会报错。

1.8 综合：5 名学生 × 3 次测验

import numpy as np

scores = np.array([
    [86, 90, 88],
    [72, 79, 81],
    [95, 93, 97],
    [60, 70, 75],
    [88, 85, 90]
], dtype=float)

student_mean = scores.mean(axis=1)
test_mean = scores.mean(axis=0)
pass_counts = (scores >= 80).sum(axis=1)

print("每人平均:", student_mean)
print("每次平均:", test_mean)
print("达标次数:", pass_counts)
检查点：原始 scores 未被原地修改；三项统计都能打印。

1.9 常见错误

错误 1：把列表 + 当成逐元素加法。

错误 2：混淆 axis=0 与 axis=1 的汇总方向。

错误 3：用整数数组做除法却期望得到小数时，注意 dtype。

错误 4：布尔条件写成 10 <= values <= 20（对数组不合法），应拆成两次比较再 &。

错误 5：形状不兼容时强行相加，未先打印 shape。
