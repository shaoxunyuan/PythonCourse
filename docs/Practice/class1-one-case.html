Class1：从一条病例理解 Python 程序

先从一条病例出发：把真实信息变成程序里的数据，再完成输入、计算与格式化输出。

1. 本次要解决的问题

课程数据里有十几万条住院记录。今天先只看一条病例：它有哪些信息？这些信息在 Python 里分别是什么？程序怎样读入它们、怎样计算、怎样输出一份可读的病例摘要？

2. Python 程序到底在处理什么

先拿一条病例：

patient_id = 12345
age_group = "[70-80)"
gender = "Female"
stay_days = 8
num_medications = 18
readmitted = "<30"

这里每一行都在做同一件事：给真实世界的信息起一个名字，并保存对应的值。

  • 变量：用来存放数据的名字，例如 stay_days
  • 标识符：变量名本身，要合法、可读
  • 值：真正保存的内容，例如 8、"Female"
  • 数据类型：值属于哪一类，决定能做什么运算
  • 表达式：能算出结果的写法，例如 stay_days + 1
  • 语句：让程序执行的完整指令，例如赋值语句
一条真实世界的信息，怎样变成程序里的数据。

3. 类型决定操作

比较下面两种写法：

stay_days + 1      # 可以：整数加 1
age_group + 1      # 不可以：字符串不能直接加整数

原因在于类型不同。常见类型：

  • int：整数，如住院天数、药物种数
  • float：小数
  • str：文本，如年龄组、性别、再入院标记
  • bool：真/假，如是否 30 天内再入院

用 type() 查看类型；需要时用 int()、float()、str() 做转换。

print(type(stay_days))       # <class 'int'>
print(type(age_group))       # <class 'str'>

stay_days = int("8")         # 字符串转整数
label = str(patient_id)      # 整数转字符串
print(age_group + " 岁段")   # 字符串可以和字符串拼接

4. 程序怎样产生结果

程序要和人交互，常用：

  • print()：把结果打印到屏幕
  • input()：从键盘读入（读到的默认是字符串）
  • f-string：把变量嵌入文本，方便格式化输出

完整流程：输入病例信息 → 计算 → 输出病例摘要。

patient_id = int(input("患者编号："))
age_group = input("年龄组（如 [70-80)）：")
gender = input("性别：")
stay_days = int(input("住院天数："))
num_medications = int(input("药物种数："))
readmitted = input("再入院标记（NO / >30 / <30）：")

readmitted_cn = "是" if readmitted == "<30" else "否"

print(f"患者编号：{patient_id}")
print(f"年龄组：{age_group}")
print(f"本次住院：{stay_days} 天")
print(f"使用药物：{num_medications} 种")
print(f"30天内再入院：{readmitted_cn}")

5. 核心实验任务

完成流程：病例输入 → 类型检查 → 简单计算 → 格式化输出。

任务 1：病例输入

  • 用 input() 读入：患者编号、年龄组、性别、住院天数、药物种数、再入院标记
  • 把编号、住院天数、药物种数转成合适的数值类型

任务 2：类型检查

  • 对关键变量使用 type() 打印类型
  • 确认数值字段是 int，文本字段是 str

任务 3：简单计算与格式化输出

  • 可做简单计算，例如“若再住 1 天，总住院天数是多少”
  • 用 f-string 输出摘要，参考格式：
患者编号：12345
年龄组：[70-80)
本次住院：8 天
使用药物：18 种
30天内再入院：是

6. 进阶挑战

加入输入合法性检查。例如：

  • 住院天数不能为负数
  • 药物数量不能为负数
  • readmitted 只能是 NO / >30 / <30

不合法时给出提示，并要求重新输入。
