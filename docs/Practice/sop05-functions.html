1.1 为什么需要函数

1.2 定义函数与 IPO

语法：

def 函数名(参数列表):
    函数体
    return 返回值
  • 以 def 开头；先定义，后调用
  • 遵循 IPO（输入 Input → 处理 Process → 输出 Output）模型
Step 1 / 定义与调用
def is_long_stay(days):
    """判断是否长住院（示例规则：≥ 7 天）"""
    return days >= 7

print(is_long_stay(8))
print(is_long_stay(4))
IPO 本例对应
输入 实参 8 / 4 → 形参 days
处理 days >= 7
输出 return 得到 True / False
Step 2 / 仅写 def 不会执行函数体
def show_patient_id(patient):
    print(patient["patient_id"])

# 此时还没有输出；需要调用：
show_patient_id(patients[0])
检查点：is_long_stay(8) 为 True；is_long_stay(4) 为 False。执行 def 只是定义函数，必须调用才会运行函数体。

1.3 参数规则

本节掌握三类参数：位置参数、默认参数、*args 可变位置参数。

Step 1 / 位置参数：按顺序对应
def stay_summary(patient_id, days):
    return f"患者 {patient_id} 住院 {days} 天"

print(stay_summary(10001, 8))
# print(stay_summary(8, 10001))  # 顺序错了，语义也错
Step 2 / 默认参数（可选参数）
def is_long_stay(days, threshold=7):
    return days >= threshold

print(is_long_stay(8))          # 使用默认阈值 7
print(is_long_stay(8, 10))      # 临时改用阈值 10
print(is_long_stay(8, threshold=9))
规则（考点）：默认参数必须放在位置参数后面。错误写法：def func(a=10, b)。
Step 3 / 可变位置参数 *args
def average_days(*days):
    """接收不定数量的住院天数，打包为元组"""
    print(type(days), days)
    if len(days) == 0:
        return None
    return sum(days) / len(days)

print(average_days(8, 4, 10))
print(average_days(8, 4, 10, 6, 9))
检查点：*args 在函数内是元组。average_days(8, 4, 10) 约为 7.333...；五天版本平均为 7.4。

1.4 return 返回值

  • 无 return：默认返回 None
  • 单个 return：返回一个对象
  • return x, y, z：返回多个值，本质返回元组
Step 1 / 无 return → None
def only_print(days):
    print(days)

result = only_print(8)
print(result)          # None
print(type(result))    # <class 'NoneType'>
Step 2 / 单个返回值
def get_stay(patient):
    return patient["time_in_hospital"]

print(get_stay(patients[0]))
Step 3 / 多返回值本质是元组
def stay_and_meds(patient):
    return patient["time_in_hospital"], patient["num_medications"]

pair = stay_and_meds(patients[0])
print(pair)
print(type(pair))

days, meds = stay_and_meds(patients[0])  # 解包
print(days, meds)
Step 4 / 区分 print 与 return
def add_one_wrong(x):
    print(x + 1)   # 只显示，不把值交回

def add_one(x):
    return x + 1   # 把值交回调用处

a = add_one_wrong(3)  # 屏幕看到 4，但 a 是 None
b = add_one(3)        # b 是 4
print(a, b)
检查点：stay_and_meds(patients[0]) 得到 (8, 18)，类型为 tuple。需要后续计算时用 return，不要只靠 print。

1.5 变量作用域与 global

不写 global 时：函数内读取全局变量可以；一旦赋值，会新建局部变量，而不是修改全局变量。
  • 函数内直接赋值 → 局部变量，外部不可访问
  • 函数内使用 global 变量名 → 声明使用全局变量，可修改其值
Step 1 / 读取全局变量
threshold = 7

def check(days):
    return days >= threshold   # 只读全局 threshold，可以

print(check(8))
Step 2 / 赋值会新建局部变量
count = 0

def bump_local():
    count = 1          # 新建局部 count，不改全局
    print("函数内", count)

bump_local()
print("函数外", count)  # 仍为 0
Step 3 / 使用 global 修改全局变量
count = 0

def bump_global():
    global count
    count = count + 1

bump_global()
bump_global()
print(count)  # 2
Step 4 / 局部变量外部不可访问
def make_label(days):
    label = "长" if days >= 7 else "短"
    return label

print(make_label(8))
# print(label)  # NameError：label 是局部变量
检查点：无 global 时函数内赋值不影响外部 count；有 global 后两次调用可使全局 count 变为 2。教学中优先用 return 传出结果，少依赖 global。

1.6 lambda 匿名函数

语法：lambda 参数: 表达式

  • 只能写单个表达式，不能写循环、分支代码块
  • 适合简短函数；可赋值后调用，也可作为参数传入
Step 1 / 赋值与调用
f = lambda x: x + 1
print(f(2))  # 3

is_long = lambda days: days >= 7
print(is_long(8))
print(is_long(4))
Step 2 / 与 def 对照
def is_long_def(days):
    return days >= 7

is_long_lambda = lambda days: days >= 7
print(is_long_def(8), is_long_lambda(8))
Step 3 / 用于排序 key（可选）
sorted_by_stay = sorted(patients, key=lambda p: p["time_in_hospital"])
for p in sorted_by_stay:
    print(p["patient_id"], p["time_in_hospital"])
检查点：lambda 只能是表达式，不能写 if/else 多行块或 for 循环体。复杂逻辑请用 def。

1.7 递归：两大必备条件

递归定义：函数在函数体内调用自身。

递归两大必备条件（缺一不可，必考）：
✅ 基例（终止条件）：不再继续递归，直接返回结果，防止无限递归
✅ 递归链条：递归调用时，参数不断向基例收敛
Step 1 / 阶乘：先看完整写法
def factorial(n):
    if n == 0 or n == 1:   # 基例
        return 1
    return n * factorial(n - 1)  # 递归链条：n → n-1 → … → 1

print(factorial(5))  # 120
要素 本例
基例 n == 0 或 n == 1 时 return 1
递归链条 factorial(n - 1)，参数变小并趋于 1
检查点：缺基例会无限递归直至栈溢出；缺收敛（例如一直调用 factorial(n)）同样无法结束。

1.8 递归执行流程与案例

执行流程：

  1. 调用函数，压入调用栈
  2. 不断递归，直到触发基例
  3. 基例返回，逐层退栈，反向计算结果
Step 1 / 手动推演 factorial(3)
factorial(3)
  → 3 * factorial(2)
       → 2 * factorial(1)
            → 1          （基例返回）
       ← 2 * 1 = 2
  ← 3 * 2 = 6
print(factorial(3))  # 6
Step 2 / 斐波那契（另一经典模板）
def fib(n):
    if n == 0:
        return 0
    if n == 1:
        return 1
    return fib(n - 1) + fib(n - 2)

print(fib(6))  # 8
Step 3 / 优缺点（概念）
  • 优点：代码简洁，天然适合分形、分支类问题（如汉诺塔、科赫雪花）
  • 缺点：递归深度有限，大量递归可能栈溢出，效率往往低于等价循环
检查点：能指出基例与递归链，并能手动推演 factorial(3) = 6、factorial(5) = 120。

1.9 代码复用与模块化

代码复用两种形式：

  • 函数复用：封装一段逻辑，多次调用（本章核心）
  • 对象复用：面向对象方式（本章仅概念，不深入）

模块化设计：分而治之——把大程序拆成多个独立模块，每个模块负责单一功能。

耦合原则（高频简答）：模块内部紧耦合，模块之间松耦合。
紧耦合：同一模块内部代码关联紧密。
松耦合：模块之间依赖少、接口简单，一处改动尽量不影响其他模块。

库的复用：Python 标准库就是模块化复用，import 后直接使用已有功能。

import math
print(math.sqrt(16))  # 4.0，不必自己写开方算法

模块化优势：易阅读、易调试、可复用、便于多人开发。

Step / 用函数拆分病例处理（分而治之）
def get_stay_days(patients):
    days = []
    for p in patients:
        days.append(p["time_in_hospital"])
    return days

def average(nums):
    if len(nums) == 0:
        return None
    return sum(nums) / len(nums)

def filter_long_stay(patients, threshold=7):
    selected = []
    for p in patients:
        if p["time_in_hospital"] >= threshold:
            selected.append(p)
    return selected

days = get_stay_days(patients)
print(average(days))
print(len(filter_long_stay(patients)))

每个函数职责单一：取天数、求平均、筛选。它们通过返回值与参数连接，而不是挤在一个巨型脚本里。

检查点：能背出「内部紧耦合，模块间松耦合」；能说出函数复用与对象复用两种形式。

1.10 综合：病例处理工具箱

把筛选与统计封装为可复用函数，输出统一摘要。

Step 1 / 完整参考代码
patients = [
    {"patient_id": 10001, "gender": "Female", "age_group": "[70-80)", "time_in_hospital": 8, "num_medications": 18, "number_inpatient": 2, "readmitted": "<30"},
    {"patient_id": 10002, "gender": "Male", "age_group": "[60-70)", "time_in_hospital": 4, "num_medications": 12, "number_inpatient": 0, "readmitted": "NO"},

    {"patient_id": 10004, "gender": "Male", "age_group": "[50-60)", "time_in_hospital": 6, "num_medications": 15, "number_inpatient": 1, "readmitted": "NO"},
    {"patient_id": 10005, "gender": "Female", "age_group": "[70-80)", "time_in_hospital": 9, "num_medications": 20, "number_inpatient": 2, "readmitted": "<30"}
]

def get_ids(patients):
    ids = []
    for p in patients:
        ids.append(p["patient_id"])
    return ids

def average_stay(patients):
    if len(patients) == 0:
        return None
    total = 0
    for p in patients:
        total = total + p["time_in_hospital"]
    return total / len(patients)

def filter_by_stay(patients, threshold=7):
    selected = []
    for p in patients:
        if p["time_in_hospital"] >= threshold:
            selected.append(p)
    return selected

def filter_early_readmit(patients):
    selected = []
    for p in patients:
        if p["readmitted"] == "<30":
            selected.append(p)
    return selected

def filter_attention(patients):
    selected = []
    for p in patients:
        if p["time_in_hospital"] >= 7 and p["number_inpatient"] >= 2:
            selected.append(p)
    return selected

def print_toolbox_summary(patients):
    long_stay = filter_by_stay(patients)
    early = filter_early_readmit(patients)
    attention = filter_attention(patients)
    print("==============================")
    print("病例处理工具箱")
    print("==============================")
    print(f"病例总数：{len(patients)}")
    print(f"平均住院天数：{average_stay(patients)}")
    print(f"长住院人数：{len(long_stay)}")
    print(f"早期再入院人数：{len(early)}")
    print(f"重点关注人数：{len(attention)}")
    print("长住院编号：")
    for pid in get_ids(long_stay):
        print(pid)
    print("早期再入院编号：")
    for pid in get_ids(early):
        print(pid)
    print("重点关注编号：")
    for pid in get_ids(attention):
        print(pid)
    print("==============================")

print_toolbox_summary(patients)
Step 2 / 模块划分说明
  • 取数工具：get_ids、average_stay
  • 筛选工具：filter_by_stay、filter_early_readmit、filter_attention
  • 展示工具：print_toolbox_summary（调用上述工具，接口简单）
检查点：总数 5，平均住院天数 7.4；长住院 3 人；早期再入院 2 人；重点关注 3 人。各筛选函数可被单独测试与复用。

1.11 常见错误

错误 1：先调用后定义。

# print(double(3))  # NameError：此时 double 尚未定义
def double(n):
    return n * 2
print(double(3))

错误 2：默认参数写在位置参数前面。

# def bad(a=7, b):  # SyntaxError
def good(b, a=7):
    return b >= a

错误 3：把 print 当成 return。

def avg(nums):
    print(sum(nums) / len(nums))  # 只显示

# result = avg([8, 4, 10])  # result 为 None，无法继续计算
def avg_ok(nums):
    return sum(nums) / len(nums)

错误 4：无 global 却以为改到了全局变量。

n = 0
def set_n():
    n = 1
set_n()
print(n)  # 仍是 0

错误 5：递归缺少基例或参数不收敛。

# def bad(n):
#     return n * bad(n)   # 无基例且不收敛 → 递归错误 / 栈溢出

def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

错误 6：在 lambda 里写多行代码块。

# 复杂逻辑用 def，不要硬塞进 lambda
def stay_level(days):
    if days >= 7:
        return "长"
    return "短"
