SOP3：程序控制结构与病例规则筛选

怎样让程序自动判断不同病例，并批量处理大量记录？完成后你将得到「病例规则筛查器」。

1. 条件判断

stay = 8
readmitted = "<30"
if stay >= 7 and readmitted == "<30":
    print("长住院且 30 天内再入院")
elif stay >= 7:
    print("长住院")
else:
    print("其他")

2. 循环与批量处理

patients = [
    {"id": 1, "stay": 8, "inpatient": 2, "emergency": 1, "readmitted": "<30"},
    {"id": 2, "stay": 3, "inpatient": 0, "emergency": 0, "readmitted": "NO"},
    {"id": 3, "stay": 10, "inpatient": 3, "emergency": 2, "readmitted": ">30"},
]

count = 0
for p in patients:
    if p["stay"] >= 7:
        count += 1
print(count, count / len(patients))

3. 核心实验

教学规则示例：

  • 住院时间 ≥ 7 天
  • 既往住院次数 ≥ 2
  • 既往急诊次数 ≥ 1
  • 30 天内再次入院（readmitted == "<30"）

完成：单条件筛选、多条件筛选、组合条件、批量处理、人数统计、比例计算。

4. 进阶任务

做一个小程序：用户可勾选多个条件，程序输出同时满足（或满足任一）条件的病例列表与统计结果。

5. 作业

作业 1

对至少 20 条病例完成四条规则的分别筛选，并输出人数与比例。

作业 2

实现“全部满足 / 任一满足”两种组合模式，并比较结果差异。
