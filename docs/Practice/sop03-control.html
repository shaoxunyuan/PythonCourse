1. 练习

1.1 为什么需要控制结构

上一节已经能够用 list of dict 表示多条病例：

patients = [
    {"patient_id": 10001, "gender": "Female", "time_in_hospital": 8, "readmitted": "<30"},
    {"patient_id": 10002, "gender": "Male", "time_in_hospital": 4, "readmitted": "NO"},
    {"patient_id": 10003, "gender": "Female", "time_in_hospital": 10, "readmitted": ">30"}
]

如果只有 3 条病例，可以手工写 patients[0]、patients[1]、patients[2]。若有 100 条病例，并要回答：

  • 哪些病例住院时间 ≥ 7 天？
  • 有多少人 30 天内再入院？
  • 女性患者的平均住院天数是多少？

就需要程序能够：根据条件做判断，并对列表中的每一条病例重复处理。本节回答三个问题：

  • 如何根据规则给出不同结果？
  • 如何自动逐条处理病例？
  • 如何一边遍历一边筛选、计数与统计？

1.2 什么是程序控制结构

默认情况下，程序按书写顺序逐行执行。控制结构改变执行路径：有的语句只在条件成立时运行，有的语句会重复运行。

结构 主要作用 病例场景示例
if / elif / else 按条件分支 判断是否长住院、是否早期再入院
for 按序列逐项重复 遍历全部病例并逐条检查
while 在条件成立时重复 重复输入直到得到合法住院天数
break / continue 提前结束或跳过本轮 找到目标后停止；跳过无效记录
结论：条件负责“要不要做”，循环负责“做多少次”。二者常一起使用。

1.3 if / else 条件判断

if 根据布尔表达式决定是否执行某段代码。缩进表示从属关系。

Step 1 / 单分支 if
time_in_hospital = 8
if time_in_hospital >= 7:
    print("长住院")
Step 2 / if / else 双分支
readmitted = "<30"
if readmitted == "<30":
    print("30天内再次入院")
else:
    print("非30天内再入院")
Step 3 / 条件来自比较与逻辑运算
time_in_hospital = 8
number_inpatient = 2
if time_in_hospital >= 7 and number_inpatient >= 2:
    print("需要重点关注")
else:
    print("常规随访")
检查点：条件表达式的结果是 bool。冒号后面的代码块必须缩进。

1.4 if / elif / else 多分支

多种互斥情况可用 elif 串联。程序按顺序检查，命中第一个成立的分支后不再继续。

Step 1 / 按再入院状态分类
readmitted = ">30"
if readmitted == "<30":
    level = "早期再入院"
elif readmitted == ">30":
    level = "延迟再入院"
elif readmitted == "NO":
    level = "未再入院"
else:
    level = "未知状态"
print(level)
Step 2 / 按住院天数分级
stay = 4
if stay >= 10:
    stay_level = "很长"
elif stay >= 7:
    stay_level = "较长"
elif stay >= 4:
    stay_level = "中等"
else:
    stay_level = "较短"
print(stay_level)
检查点：stay = 4 时，结果为「中等」。分支顺序会影响结果，应先写更具体或优先级更高的条件。

1.6 for：遍历列表

for 用于按顺序取出序列中的每一个元素并重复处理。

Step 1 / 遍历数值列表
stay_days = [3, 5, 8, 4, 10]
for days in stay_days:
    print(days)
Step 2 / 遍历时做判断
stay_days = [3, 5, 8, 4, 10]
for days in stay_days:
    if days >= 7:
        print(days, "长住院")
Step 3 / 累加统计
stay_days = [3, 5, 8, 4, 10]
total = 0
for days in stay_days:
    total = total + days
print(total)
print(total / len(stay_days))
检查点：总和为 30，平均值为 6.0。for 变量名可自定，例如 days、p、patient。

1.7 for：遍历病例列表

对 list of dict，循环变量通常是一条病例字典。

Step 1 / 建立病例列表
patients = [
    {"patient_id": 10001, "gender": "Female", "time_in_hospital": 8, "num_medications": 18, "readmitted": "<30"},
    {"patient_id": 10002, "gender": "Male", "time_in_hospital": 4, "num_medications": 12, "readmitted": "NO"},
    {"patient_id": 10003, "gender": "Female", "time_in_hospital": 10, "num_medications": 21, "readmitted": ">30"},
    {"patient_id": 10004, "gender": "Male", "time_in_hospital": 6, "num_medications": 15, "readmitted": "NO"},
    {"patient_id": 10005, "gender": "Female", "time_in_hospital": 9, "num_medications": 20, "readmitted": "<30"}
]
Step 2 / 逐条输出关键字段
for p in patients:
    print(p["patient_id"], p["time_in_hospital"], p["readmitted"])
Step 3 / 筛选长住院病例
long_stay_patients = []
for p in patients:
    if p["time_in_hospital"] >= 7:
        long_stay_patients.append(p)
print(len(long_stay_patients))
print(long_stay_patients[0]["patient_id"])
检查点：长住院病例有 3 条；第一条筛选结果的编号为 10001。

1.8 range() 与计数

range() 生成一段整数序列，常与 for 配合完成固定次数循环，或按索引访问列表。

Step 1 / range 基本用法
for i in range(5):
    print(i)

for i in range(1, 6):
    print(i)
Step 2 / 按索引遍历病例
for i in range(len(patients)):
    print(i, patients[i]["patient_id"])
Step 3 / 计数器
early_count = 0
for p in patients:
    if p["readmitted"] == "<30":
        early_count += 1
print(early_count)
检查点：早期再入院人数为 2。early_count += 1 等价于 early_count = early_count + 1。

1.10 while 循环

while 在条件为真时反复执行。适合“事先不知道循环几次，但知道停止条件”的场景。

Step 1 / 基本 while
i = 0
while i < 3:
    print(i)
    i += 1
Step 2 / 输入校验（示意）
# 下面示例用于理解 while；课堂练习可用固定值代替反复输入
stay_days = -1
while stay_days < 0:
    stay_days = int(input("请输入非负住院天数："))
print("住院天数：", stay_days)
Step 3 / while 与列表处理
stay_days = [3, 5, 8, 4, 10]
i = 0
while i < len(stay_days):
    if stay_days[i] >= 7:
        print(stay_days[i])
    i += 1
检查点：遍历已知列表时，通常优先使用 for；需要按条件反复尝试时，更适合 while。

1.11 break 与 continue

break 立刻结束整个循环；continue 跳过本轮剩余语句，进入下一轮。

Step 1 / break：找到后停止
target = None
for p in patients:
    if p["readmitted"] == "<30":
        target = p
        break
print(target["patient_id"])
Step 2 / continue：跳过不符合条件的记录
for p in patients:
    if p["time_in_hospital"] < 7:
        continue
    print(p["patient_id"], p["time_in_hospital"])
检查点：break 后通常只保留第一个命中对象；continue 后仍会继续处理后续病例。

1.12 组合：筛选与统计

把条件判断与循环组合，即可完成规则处理中的常见任务。

Step 1 / 多条件筛选
focus = []
for p in patients:
    if p["time_in_hospital"] >= 7 and p["readmitted"] == "<30":
        focus.append(p)
print(len(focus))
for p in focus:
    print(p["patient_id"])
Step 2 / 分组计数
count_lt30 = 0
count_gt30 = 0
count_no = 0
for p in patients:
    if p["readmitted"] == "<30":
        count_lt30 += 1
    elif p["readmitted"] == ">30":
        count_gt30 += 1
    elif p["readmitted"] == "NO":
        count_no += 1
print(count_lt30, count_gt30, count_no)
Step 3 / 条件求和与平均
female_total = 0
female_count = 0
for p in patients:
    if p["gender"] == "Female":
        female_total += p["time_in_hospital"]
        female_count += 1
print(female_count)
print(female_total / female_count)
检查点：女性病例 3 人；女性平均住院天数为 9.0。先计数再求平均，避免除以 0。

1.13 综合：病例规则处理器 V0.3

将本节知识组合为可运行程序：对病例列表执行规则判断、筛选与统计。

Step 1 / 完整示例
patients = [
    {"patient_id": 10001, "gender": "Female", "age_group": "[70-80)", "time_in_hospital": 8, "num_medications": 18, "number_inpatient": 2, "readmitted": "<30"},
    {"patient_id": 10002, "gender": "Male", "age_group": "[60-70)", "time_in_hospital": 4, "num_medications": 12, "number_inpatient": 0, "readmitted": "NO"},
    {"patient_id": 10003, "gender": "Female", "age_group": "[80-90)", "time_in_hospital": 10, "num_medications": 21, "number_inpatient": 3, "readmitted": ">30"},
    {"patient_id": 10004, "gender": "Male", "age_group": "[50-60)", "time_in_hospital": 6, "num_medications": 15, "number_inpatient": 1, "readmitted": "NO"},
    {"patient_id": 10005, "gender": "Female", "age_group": "[70-80)", "time_in_hospital": 9, "num_medications": 20, "number_inpatient": 2, "readmitted": "<30"}
]

long_stay = []
early_readmit = []
attention = []

for p in patients:
    if p["time_in_hospital"] >= 7:
        long_stay.append(p)
    if p["readmitted"] == "<30":
        early_readmit.append(p)
    if p["time_in_hospital"] >= 7 and p["number_inpatient"] >= 2:
        attention.append(p)

total_stay = 0
for p in patients:
    total_stay += p["time_in_hospital"]
avg_stay = total_stay / len(patients)

print("==============================")
print("病例规则处理摘要")
print("==============================")
print(f"病例总数：{len(patients)}")
print(f"长住院人数：{len(long_stay)}")
print(f"早期再入院人数：{len(early_readmit)}")
print(f"重点关注人数：{len(attention)}")
print(f"平均住院天数：{avg_stay}")
print("长住院编号：")
for p in long_stay:
    print(p["patient_id"])
print("==============================")

1.14 常见错误

错误 1：忘记冒号或缩进不正确。

# if time_in_hospital >= 7   # 缺少冒号
# print("长住院")            # 应缩进到 if 内部

错误 2：用 = 做比较。

readmitted = "<30"
# if readmitted = "<30":   # 错误：这是赋值
if readmitted == "<30":
    print("早期再入院")

错误 3：while 忘记更新循环变量，导致死循环。

i = 0
while i < 3:
    print(i)
    i += 1   # 不要漏掉这一步

错误 4：在空列表上求平均。

selected = []
# print(sum_days / len(selected))  # 可能 ZeroDivisionError
if len(selected) > 0:
    print(sum_days / len(selected))
else:
    print("没有符合条件的病例")

错误 5：修改正在遍历的列表本身（高级场景易出错）。初学阶段建议：遍历原列表，把结果追加到新列表。

result = []
for p in patients:
    if p["time_in_hospital"] >= 7:
        result.append(p)

现在已经能对病例列表自动筛选与统计。若同样的规则要在多处重复使用，或希望把“判断长住院”“统计再入院”整理成可复用工具，需要进一步学习函数与模块化。这些问题将在后续实验中继续展开。
