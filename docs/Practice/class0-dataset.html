Class0：数据集

先看真实数据长什么样，再理解一行、一列在程序里对应什么。

1. 数据文件在哪里

课程数据在仓库根目录的 data/ 中：

  • diabetic_data.csv：主数据，住院记录（约 19 MB）
  • IDS_mapping.csv：数字编码的文字说明

CSV 就是用逗号分隔的表格文本。第一行通常是列名（表头），后面每一行是一条记录。

3. 一行代表什么

全表不同 patient_nbr 约 71,518 个。因此：

101,766 行 ≠ 101,766 名患者。
一行 = 一次住院记录（encounter）。同一患者可能有多次住院。
  • patient_nbr：患者编号（人）
  • encounter_id：本次住院编号（事件）
患者 patient_nbr
        ↓
可能存在多次住院
        ↓
encounter_id 1
encounter_id 2
encounter_id 3
……

数数据时要分清：你数的是住院次数，还是患者人数。

4. 字段分类速览

50 个字段可以按用途分组理解：

  • 基本信息：race、gender、age、weight
  • 入院相关：admission_type_id、discharge_disposition_id、admission_source_id、time_in_hospital
  • 医疗过程：num_lab_procedures、num_procedures、num_medications、number_outpatient、number_emergency、number_inpatient
  • 诊断：diag_1、diag_2、diag_3、number_diagnoses
  • 检验：max_glu_serum、A1Cresult
  • 药物：如 metformin、glipizide、insulin 等
  • 治疗变化：change、diabetesMed
  • 再入院：readmitted（NO / >30 / <30）

readmitted 实际分布：

  • NO：54,864
  • >30：35,545
  • <30：11,357

原始数据里常见 ?，表示缺失或未知（例如部分行的 weight、payer_code）。

6. 用病例字段写 Python

下面用真实字段直接对照几种常见写法：

6.1 变量、赋值、标识符

patient_nbr = 55629189
time_in_hospital = 3
readmitted = ">30"

左边是标识符（变量名），右边是值，= 是赋值。

6.2 数据类型：数字 vs 文本

  • time_in_hospital、num_medications 是 int，可以加减
  • gender、age、readmitted 是 str，不能直接 + 1
  • diabetesMed == "Yes" 的判断结果是 bool
print(type(3))            # <class 'int'>
print(type("Female"))     # <class 'str'>
print(type(True))         # <class 'bool'>

print(3 + 1)              # 4
# print("[10-20)" + 1)    # 报错：类型不匹配

6.3 字符串与特殊符号

age 写成 "[10-20)"，readmitted 写成 "<30" 或 ">30"。尖括号、中括号都是字符串内容的一部分，不是数学比较符。

age = "[10-20)"
readmitted = "<30"
print(age)
print(readmitted == "<30")   # True

6.4 表达式、比较、条件

stay = 3
meds = 18
long_stay = stay >= 3
many_meds = meds > 10
early_readmit = (readmitted == "<30")

if early_readmit:
    print("30 天内再入院")
else:
    print("不是 30 天内再入院")

6.5 列表：多条记录放在一起

stays = [1, 3, 2, 2, 1]          # 前 5 行的 time_in_hospital
print(len(stays))
print(sum(stays) / len(stays))   # 平均住院天数

6.6 缺失值 ? 也是数据的一部分

weight = "?"
if weight == "?":
    print("体重缺失")
