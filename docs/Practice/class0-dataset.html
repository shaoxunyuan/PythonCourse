Class0：数据集

本页不是正式编程实验，而是整个学期项目的数据背景介绍。开始 Class1 之前，先弄清：我们在处理什么数据、数据有多大、一行代表什么。

1. 数据文件

课程数据存放在仓库的 data/ 目录：

  • diabetic_data.csv：主数据，住院记录
  • IDS_mapping.csv：辅助编码说明

2. 数据维度与一行含义

diabetic_data.csv 实际维度为 101,766 行 × 50 列。不同 patient_nbr 数量为 71,518。

101,766 行并不代表 101,766 名患者。
一行表示一次住院记录（encounter），不是一名唯一患者。同一名患者可能多次住院。
  • patient_nbr：患者编号
  • encounter_id：一次具体住院记录编号
患者 patient_nbr
        ↓
可能存在多次住院
        ↓
encounter_id 1
encounter_id 2
encounter_id 3
……

3. 数据主要包含什么

50 个字段大致包括：患者基本信息、入院信息、医疗过程、诊断、检验、糖尿病相关药物、治疗变化，以及再入院字段 readmitted。

readmitted 主要取值与条数：

  • NO：54,864
  • >30：35,545
  • <30：11,357

本课程不以机器学习预测为主要目标。readmitted 主要用于练习条件判断、筛选、统计、可视化与综合分析。

4. IDS_mapping.csv

这是辅助编码说明文件（约 67 行数据 × 2 列），用于解释 admission_type_id、discharge_disposition_id、admission_source_id 等数字编码。例如 admission_type_id = 1 对应 Emergency。

后续可用于练习字典、映射、文件读取、数据关联与转换。

5. 这份数据在课程中的用途

它不是为了让你学医学诊断，也不是为了训练复杂机器学习模型，而是整门课的统一数据主线：从一条病例逐步过渡到完整真实数据、pandas、可视化、大模型 API 与 Web 平台。

本数据仅用于 Python 编程、数据处理和软件开发教学。课程中的筛选规则、统计结果以及大模型生成内容，均不用于临床诊断、治疗决策或真实医疗活动。
