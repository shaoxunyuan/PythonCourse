练习方式 本地运行代码并完成任务，再通过雨课堂填写实验记录

1. 练习

1.1 报错不等于程序报废

语法错误会在运行前就拦住你；运行时异常发生在程序已经开始执行之后。异常可以被捕获和处理，不一定意味着整次实验失败。

Step 1 / 先观察三类常见异常
print(int("12"))
# print(int("十二"))          # ValueError
# print(10 / 0)               # ZeroDivisionError
# open("no_such_file.csv")    # FileNotFoundError
先预测：把上面三行分别取消注释运行，终端会停在哪一行？错误类型分别是什么？
检查点：能说出 ValueError、ZeroDivisionError、FileNotFoundError 各自常见触发条件。

1.2 try / except 处理单个异常

把“可能失败”的代码放进 try，用 except 接住指定异常，程序可以继续往下走。

Step 1 / 失败输入
text = "abc"
try:
    days = int(text)
    print("转换成功:", days)
except ValueError:
    print("转换失败：不是整数文本")
Step 2 / 成功输入
text = "8"
try:
    days = int(text)
    print("转换成功:", days)
except ValueError:
    print("转换失败：不是整数文本")
检查点：失败时输出「转换失败…」；成功时输出 转换成功: 8。

1.3 多个 except 与 else / finally

else 只在没有异常时执行；finally 无论成败都会执行，不代表错误已被修好。

def demo(a, b):
    try:
        result = a / b
    except ZeroDivisionError:
        print("除零了")
        result = None
    except TypeError:
        print("类型不对")
        result = None
    else:
        print("计算成功")
    finally:
        print("收尾：无论成败都会走到这里")
    return result

print("结果1:", demo(10, 2))
print("结果2:", demo(10, 0))
检查点：成功路径看到「计算成功」和「收尾…」；除零路径看到「除零了」和「收尾…」，没有「计算成功」。

1.4 raise：主动拒绝无效数据

raise ValueError(...) 是主动抛出异常，不是简单打印一行错误文字。调用方可以选择捕获。

def parse_stay(text):
    try:
        days = int(text)
    except ValueError as exc:
        raise ValueError("住院天数必须是整数") from exc
    if days < 0:
        raise ValueError("住院天数不能为负数")
    return days

for value in ["8", "abc", "-2"]:
    try:
        print(value, parse_stay(value))
    except ValueError as error:
        print(value, "校验失败：", error)

预期输出：

8 8
abc 校验失败： 住院天数必须是整数
-2 校验失败： 住院天数不能为负数
检查点：8 成功；abc 与 -2 分别报告不同原因。

1.5 用函数做数据合法性校验

区分两类问题：格式错误（无法转换成数字）与业务规则不满足（年龄不合理、天数不能为负）。

def parse_age(text):
    try:
        age = int(text)
    except ValueError as exc:
        raise ValueError("年龄必须是整数") from exc
    if age < 0 or age > 120:
        raise ValueError("年龄超出合理范围")
    return age

samples = ["45", "", "130", "十八"]
for s in samples:
    try:
        print(repr(s), "->", parse_age(s))
    except ValueError as err:
        print(repr(s), "->", err)
检查点：空字符串、超范围、非数字都能给出可读原因；合法年龄正常返回。

1.6 综合：校验小型病例 CSV

用标准库 csv 读取教学模拟病例；无效行写入错误记录，有效行写入清洗结果。不要默默丢弃异常。

Step 1 / 准备教学数据 cases_raw.csv（UTF-8）
# case_id,age,stay_days
# C001,45,5
# C002,abc,3
# C003,60,-1
# C004,33,8
Step 2 / 逐行校验并分流
import csv
from pathlib import Path

src = Path("cases_raw.csv")
ok_path = Path("cases_valid.csv")
err_path = Path("cases_errors.csv")

def parse_stay(text):
    try:
        days = int(text)
    except ValueError as exc:
        raise ValueError("住院天数必须是整数") from exc
    if days < 0:
        raise ValueError("住院天数不能为负数")
    return days

def parse_age(text):
    try:
        age = int(text)
    except ValueError as exc:
        raise ValueError("年龄必须是整数") from exc
    if age < 0 or age > 120:
        raise ValueError("年龄超出合理范围")
    return age

valid_rows = []
error_rows = []

with src.open("r", encoding="utf-8", newline="") as f:
    reader = csv.DictReader(f)
    for i, row in enumerate(reader, start=2):  # 表头为第 1 行
        try:
            case_id = (row.get("case_id") or "").strip()
            if not case_id:
                raise ValueError("编号不能为空")
            age = parse_age(row.get("age", ""))
            stay = parse_stay(row.get("stay_days", ""))
            valid_rows.append({"case_id": case_id, "age": age, "stay_days": stay})
        except ValueError as err:
            error_rows.append({"line": i, "raw": dict(row), "error": str(err)})

with ok_path.open("w", encoding="utf-8", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=["case_id", "age", "stay_days"])
    writer.writeheader()
    writer.writerows(valid_rows)

with err_path.open("w", encoding="utf-8", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=["line", "error", "raw"])
    writer.writeheader()
    for item in error_rows:
        writer.writerow({"line": item["line"], "error": item["error"], "raw": item["raw"]})

print("有效行:", len(valid_rows), "错误行:", len(error_rows))
检查点：单行失败不中断后续行；错误原因写入错误文件，有效数据不混入无效值。

1.7 常见错误

错误 1：用裸 except: 吞掉所有异常，排错时看不到真正原因。

# 不推荐
# try:
#     ...
# except:
#     pass

错误 2：把 raise 当成 print，以为抛出后还能继续同一段逻辑。

错误 3：捕获了异常却不记录行号/原始内容，事后无法复查。

错误 4：文件不存在时只打印“失败”，不区分 FileNotFoundError 与内容校验错误。

错误 5：校验失败后仍把原字符串写进“有效结果”。
