实验10：Matplotlib数据可视化

从一周测量值的变化开始。完成本节后，能按数据关系选择折线/柱状/散点/直方，并保存可提交的高清图。

本课目标 掌握 Figure/Axes、四类基本图、标题轴标签图例，以及 savefig 输出
项目阶段 图表呈现。把汇总结果画成可阅读、可提交的图片
练习方式 本地运行代码并完成任务，再通过雨课堂填写实验记录

1. 练习

1.1 先看数据关系，再选图

连续趋势适合折线；类别对比适合柱状；两数值关系适合散点；单变量分布适合直方图。不要先决定“画什么图”再硬凑数据。

分类计数不要用折线把类别连成“趋势”；直方图用于分布，不等于柱状图的类别对比。
检查点：能根据问题选择合适图型，并说出不合适的一种画法。

1.2 Figure 与 Axes：推荐 subplots

import matplotlib.pyplot as plt

weeks = [1, 2, 3, 4, 5]
values = [12, 14, 13, 17, 20]
fig, ax = plt.subplots(figsize=(6, 4))
ax.plot(weeks, values, marker="o", color="black")
ax.set(xlabel="Week", ylabel="Value", title="Measurement trend")
fig.tight_layout()
fig.savefig("trend.png", dpi=300)
# plt.show()
print("已保存 trend.png")

中文字体因机器而异，本节示例默认英文标签；若使用中文，请在本机配置可用字体。

检查点：理解 Figure 是整张画布，Axes 是坐标系；优先 fig, ax = plt.subplots()。

1.3 柱状图：类别对比

import matplotlib.pyplot as plt

groups = ["A", "B", "C"]
counts = [12, 7, 15]
fig, ax = plt.subplots(figsize=(6, 4))
ax.bar(groups, counts, color="black")
ax.set(xlabel="Group", ylabel="Count", title="Sample counts by group")
fig.tight_layout()
fig.savefig("bar_counts.png", dpi=300)
print("已保存 bar_counts.png")
检查点：柱状图比较的是类别数值；注意区分“样本数”与“均值”。

1.4 散点图：两变量关系

import matplotlib.pyplot as plt

age = [30, 40, 50, 60, 70]
stay = [3, 5, 4, 8, 9]
fig, ax = plt.subplots(figsize=(6, 4))
ax.scatter(age, stay, color="black")
ax.set(xlabel="Age", ylabel="Stay days", title="Age vs stay (demo)")
fig.tight_layout()
fig.savefig("scatter_age_stay.png", dpi=300)
print("已保存 scatter_age_stay.png")
相关不等于因果：散点只能提示共变关系，不能直接下因果结论。
检查点：两轴都是数值变量。

1.5 直方图：分布与 bins

import matplotlib.pyplot as plt

values = [3, 4, 4, 5, 5, 5, 6, 7, 8, 9, 10, 12]
fig, ax = plt.subplots(figsize=(6, 4))
ax.hist(values, bins=5, color="black", edgecolor="white")
ax.set(xlabel="Value", ylabel="Frequency", title="Distribution (bins=5)")
fig.tight_layout()
fig.savefig("hist_values.png", dpi=300)
print("已保存 hist_values.png")
检查点：改变 bins 会改变呈现；说明里写清分箱设置。

1.6 标签、图例、网格与保存

import matplotlib.pyplot as plt

weeks = [1, 2, 3, 4, 5]
a = [12, 14, 13, 17, 20]
b = [10, 11, 15, 16, 18]
fig, ax = plt.subplots(figsize=(6, 4))
ax.plot(weeks, a, marker="o", label="Series A")
ax.plot(weeks, b, marker="s", label="Series B")
ax.set(xlabel="Week", ylabel="Value", title="Two series")
ax.legend()
ax.grid(True, linestyle="--", alpha=0.4)
fig.tight_layout()
fig.savefig("two_series.png", dpi=300)
print("已保存 two_series.png")
检查点：标题、轴标签、图例齐全；使用 tight_layout 与足够 DPI。

1.7 同一组数据画四种图

使用同一组小型模拟测量数据，分别输出折线、柱状、散点、直方，并各用一句话说明该图回答什么问题。

检查点：四张 PNG 均能打开；每张图有标题与轴标签。

1.8 常见错误

错误 1：用折线连接无序类别。

错误 2：直方图与柱状图混淆。

错误 3：缺少单位或轴标签。

错误 4：中文显示为方框——先查字体配置。

错误 5：只 plt.show() 不保存文件。
