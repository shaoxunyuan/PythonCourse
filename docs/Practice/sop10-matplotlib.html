实验10：Matplotlib 基础可视化

使用 Python 绘制折线图、柱状图和散点图，学会添加标题与坐标轴名称，并将图表保存为图片。

本课目标 掌握 plt.plot、plt.bar、plt.scatter，学会标题、坐标轴标签与保存图片
项目阶段 把整理好的数据画成图，让结果可以直接放进报告
练习方式 本地运行代码并完成任务，再通过雨课堂填写实验记录

1. 练习

1.1 环境准备

先确认 Python 可用，再安装 Matplotlib，并验证能否成功导入。

python --version
python -m pip --version
python -m pip install matplotlib -i https://pypi.tuna.tsinghua.edu.cn/simple
python -c "import matplotlib; import matplotlib.pyplot as plt; print(matplotlib.__version__)"

使用 python -m pip 更容易保证安装到当前正在使用的解释器。若系统里只有 python3，把命令中的 python 换成 python3；Windows 上也可以按实际环境使用 py。最后一行能打印出版本号，就说明安装成功。

检查点：安装与导入成功，能打印出 Matplotlib 版本号。

1.2 绘制折线图

一周运动时间适合用折线图观察变化。

import matplotlib.pyplot as plt

days = ["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"]
minutes = [20, 30, 15, 40, 35, 60, 45]
plt.plot(days, minutes, marker="o", color="blue")
plt.show()
检查点：能看到七个数据点；改动一项 minutes 后，折线相应改变。

1.3 绘制柱状图

不同社团的参与人数适合用柱状图比较大小。

import matplotlib.pyplot as plt

clubs = ["Sports", "Music", "Art", "Coding"]
students = [32, 25, 18, 28]
plt.bar(clubs, students, color="skyblue")
plt.show()
检查点：四根柱子与四个社团一一对应；能指出参与人数最多的社团。

1.4 绘制散点图

下面的学习时间与成绩都是模拟数据，仅用于观察两个变量同时变化的现象。

import matplotlib.pyplot as plt

hours = [1, 2, 3, 4, 5, 6]
scores = [56, 60, 65, 74, 79, 86]
plt.scatter(hours, scores, s=60, color="teal", alpha=0.8)
plt.show()
散点只能提示两个变量一起变化的趋势，不能据此直接得出因果结论；数据为模拟示例。
检查点：散点数量与数据对数量相等；能区分点的大小 s、颜色 color 和透明度 alpha。

1.5 标题、坐标轴与保存

把上面的折线图补上标题和坐标轴名称，再保存成图片。

import matplotlib.pyplot as plt

days = ["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"]
minutes = [20, 30, 15, 40, 35, 60, 45]
plt.plot(days, minutes, marker="o", color="blue")
plt.title("Weekly Exercise Time")
plt.xlabel("Day")
plt.ylabel("Minutes")
plt.grid(True, alpha=0.3)
plt.savefig("exercise10.png", dpi=150, bbox_inches="tight")
plt.show()

图片通常写入 Python 的当前工作目录。想确认位置，可以运行 import os; print(os.getcwd())，或用文件管理器查看。先 savefig 再 show，可以避免部分环境下窗口关闭后保存出空白图。

检查点：生成的 exercise10.png 能正常打开，标题与横纵轴名称完整。

1.6 常见错误

错误 1：ModuleNotFoundError: No module named 'matplotlib'——确认安装时使用的 Python 与运行代码的 Python 是同一个。

错误 2：ValueError（x/y 长度不一致）——核对两个列表的元素个数相同。

错误 3：图片保存后找不到——检查当前工作目录与文件名。

错误 4：中文标题显示为方框——优先使用英文标题；如使用中文，需要在改图前配置本机支持中文的字体。

错误 5：图片空白或保存失败——检查顺序，先画图、再 savefig、最后 show。
