SOP5：动态函数与可配置病例规则

程序能不能在运行过程中动态选择“使用哪个函数”？完成后你将得到「动态病例规则系统」。

1. 函数也是对象

def long_stay(p):
    return p["time_in_hospital"] >= 7

def readmitted_30d(p):
    return p["readmitted"] == "<30"

rules = {
    "long_stay": long_stay,
    "frequent_inpatient": lambda p: p.get("number_inpatient", 0) >= 2,
    "readmitted_30d": readmitted_30d,
}

name = "long_stay"
print(rules[name]({"time_in_hospital": 8}))

2. map / filter / sorted

patients = [{"id": 1, "time_in_hospital": 8}, {"id": 2, "time_in_hospital": 3}]
selected = list(filter(rules["long_stay"], patients))
ordered = sorted(patients, key=lambda p: p["time_in_hospital"], reverse=True)

3. 核心实验

  • 构建规则字典 rules
  • 运行时让用户选择一个规则或多个规则
  • 对病例列表完成筛选并输出结果

4. 进阶任务

def apply_rules(patients, selected, mode="all"):
    funcs = [rules[n] for n in selected]
    out = []
    for p in patients:
        ok = all(f(p) for f in funcs) if mode == "all" else any(f(p) for f in funcs)
        if ok:
            out.append(p)
    return out
