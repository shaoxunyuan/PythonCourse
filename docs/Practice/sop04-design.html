1.7 变量变化与程序执行顺序

先预测输出，再运行核对。追踪每一轮循环中变量如何变化。

Step 1 / 先预测，再运行
total = 0
stay_days = [3, 5, 8]
for days in stay_days:
    total = total + days
    print(days, total)
print(total)
循环轮次 days 执行前 total 执行后 total
1 3 0 3
2 5 3 8
3 8 8 16

循环结束后再打印一次 total，结果为 16。

Step 2 / 增加 if，追踪哪些语句被执行
total = 0
count_ge5 = 0
stay_days = [3, 5, 8]
for days in stay_days:
    total = total + days
    if days >= 5:
        count_ge5 = count_ge5 + 1
        print("计入", days)
    else:
        print("跳过累计条件", days)
print(total, count_ge5)

days = 3 时走 else；5 与 8 时走 if。最终 total 仍为 16，count_ge5 为 2。

Step 3 / 错误示例：累计变量放在循环内部
# 错误示例：每轮都把 total 重置为 0
stay_days = [3, 5, 8]
for days in stay_days:
    total = 0
    total = total + days
    print(days, total)
print("最终", total)

观察：每轮打印的第二列都等于当前 days，最终 total 只剩最后一轮的 8。

Step 4 / 修正
total = 0
stay_days = [3, 5, 8]
for days in stay_days:
    total = total + days
print(total)
检查点：正确写法最终 total = 16；错误写法最终通常为 8。累计变量应放在循环外面初始化。

1.8 函数调用与结果传递

本节只介绍最简单的函数定义、调用与 return，为后续函数专题做衔接。

Step 1 / 定义与调用
def average_stay(days):
    total = sum(days)
    return total / len(days)

stay_days = [8, 4, 10]
result = average_stay(stay_days)
print(result)
步骤 发生了什么
执行 def 定义函数，此时不执行函数体
调用 average_stay(stay_days) 把列表作为实参传入
函数内 days 形参，接收传入的列表
return ... 把计算结果交回调用位置
result = ... 外部变量接收返回值

形参名不必与外部变量同名。例如外部叫 stay_days，形参叫 days，只要调用时顺序对应即可。

Step 2 / 两个函数通过返回值连接
def get_stay_days(patients):
    days = []
    for p in patients:
        days.append(p["time_in_hospital"])
    return days

def average_stay(days):
    if len(days) == 0:
        return None
    return sum(days) / len(days)

days = get_stay_days(patients)
result = average_stay(days)
print(days)
print(result)

get_stay_days 返回天数列表；该列表再作为实参传给 average_stay。若列表为空，返回 None，避免除零。

Step 3 / 自行追踪
def count_long_stay(patients, threshold):
    n = 0
    for p in patients:
        if p["time_in_hospital"] >= threshold:
            n = n + 1
    return n

value = count_long_stay(patients, 7)
print(value)

填写：实参是什么？形参是什么？返回值是多少？最终打印结果是多少？

检查点：average_stay([8, 4, 10]) 结果约为 7.333...；对五条病例，get_stay_days 得到 [8, 4, 10, 6, 9]，平均值 7.4；count_long_stay(patients, 7) 返回 3。

1.10 常见错误

错误 1：访问不存在的字典键。

patient = {"patient_id": 10001, "time_in_hospital": 8}
# print(patient["stay"])  # 错误示例：KeyError
print(patient.get("stay"))
print(patient["time_in_hospital"])

错误 2：累计变量放在循环内部。

# 错误示例
for days in [3, 5, 8]:
    total = 0
    total = total + days
# 修正
total = 0
for days in [3, 5, 8]:
    total = total + days
print(total)  # 16

错误 3：误用 and / or。

# and：两个条件都要成立；or：满足其一即可
p = {"time_in_hospital": 8, "readmitted": "NO"}
print(p["time_in_hospital"] >= 7 and p["readmitted"] == "<30")  # False
print(p["time_in_hospital"] >= 7 or p["readmitted"] == "<30")   # True

错误 4：把 print 与 return 混为一谈。

def add_one(x):
    print(x + 1)   # 只显示，不把值交回
    return x + 1   # 才把值交回调用处

value = add_one(3)
print(value)

错误 5：定义函数后忘记调用。

def show_id(patient):
    print(patient["patient_id"])

patient = {"patient_id": 10001}
# 仅写 def 不会输出；需要调用：
show_id(patient)

错误 6：误以为形参必须与实参同名。

def double(n):
    return n * 2

stay = 8
print(double(stay))  # 形参是 n，实参是 stay，仍然正确

错误 7：空列表直接求平均。

selected = []
if len(selected) == 0:
    print("没有符合条件的病例")
else:
    print(sum(selected) / len(selected))

错误 8：缩进错误导致统计位置不对。

# 错误示例：print 缩进进循环，会打印多次
total = 0
for days in [3, 5, 8]:
    total = total + days
    # print(total)  # 每轮都打印
print(total)  # 修正：循环结束后打印一次
