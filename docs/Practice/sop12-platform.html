1. 练习

1.1 最小 Streamlit 页面

综合项目承接文件、异常、NumPy、pandas、Matplotlib、API，不单独深入 Web 后端框架。教学演示不等于生产部署。

import streamlit as st

st.title("病例数据分析演示")

在终端运行：streamlit run app.py。

检查点：能启动页面并看到标题文字。

1.2 读取内置模拟数据 / 上传 CSV

import streamlit as st
import pandas as pd

st.title("病例数据分析演示")
df = pd.DataFrame({
    "group": ["A", "B", "A", "B"],
    "stay_days": [4, 7, 5, 8]
})
uploaded = st.file_uploader("可选：上传 CSV", type=["csv"])
if uploaded is not None:
    try:
        df = pd.read_csv(uploaded)
    except Exception as exc:
        st.error(f"读取失败：{exc}")
if df.empty:
    st.warning("当前无数据")
else:
    st.dataframe(df)
检查点：无上传时用内置模拟数据；空文件或缺列要有提示。

1.3 预览与基本信息

import streamlit as st
import pandas as pd

df = pd.DataFrame({
    "group": ["A", "B", "A", "B", None],
    "stay_days": [4, 7, 5, 8, 6]
})
st.metric("记录数", len(df))
st.metric("分组数", df["group"].nunique(dropna=True))
st.write("缺失率（按列）")
st.write((df.isna().mean() * 100).round(1).astype(str) + "%")
st.dataframe(df)
检查点：展示记录数、分组数与缺失概况。

1.4 侧栏筛选与脚本重跑

每次交互都会从头执行脚本。

import streamlit as st
import pandas as pd

df = pd.DataFrame({
    "group": ["A", "B", "A", "B"],
    "stay_days": [4, 7, 5, 8]
})
group = st.sidebar.selectbox("选择组别", sorted(df["group"].dropna().unique()))
subset = df.loc[df["group"] == group]
st.metric("病例数", len(subset))
st.dataframe(subset)
检查点：切换组别后表格与指标随之更新。

1.5 汇总 + Matplotlib 图

import streamlit as st
import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame({
    "group": ["A", "B", "A", "B", "A"],
    "stay_days": [4, 7, 5, 8, 6]
})
summary = df.groupby("group", as_index=False)["stay_days"].mean()
st.subheader("分组平均住院天数")
st.dataframe(summary)

fig, ax = plt.subplots(figsize=(5, 3))
ax.bar(summary["group"], summary["stay_days"], color="black")
ax.set(xlabel="Group", ylabel="Mean stay", title="Mean stay by group")
fig.tight_layout()
st.pyplot(fig)
检查点：表格与图一致。

1.6 导出当前筛选结果

import streamlit as st
import pandas as pd

df = pd.DataFrame({"group": ["A", "B"], "stay_days": [4, 7]})
group = st.selectbox("组别", ["A", "B"])
subset = df.loc[df["group"] == group]
csv_bytes = subset.to_csv(index=False).encode("utf-8-sig")
st.download_button(
    label="下载当前筛选 CSV",
    data=csv_bytes,
    file_name=f"subset_{group}.csv",
    mime="text/csv",
)
检查点：下载内容与当前筛选一致。

1.7 错误提示与无数据状态

import streamlit as st
import pandas as pd

df = pd.DataFrame({"group": ["A"], "stay_days": [4]})
choice = st.selectbox("组别", ["A", "B", "未知组"])
subset = df.loc[df["group"] == choice]
if subset.empty:
    st.info("当前筛选无数据，请换一个组别或检查上传文件列名。")
else:
    st.success(f"共 {len(subset)} 条")
    st.dataframe(subset)
检查点：未知组别/空数据有可读提示。

1.8 常见错误

错误 1：用 python app.py 而不是 streamlit run app.py。

错误 2：上传后不校验列名。

错误 3：下载内容与筛选不一致。

错误 4：上传真实身份信息。

错误 5：缺少 requirements.txt / README。
