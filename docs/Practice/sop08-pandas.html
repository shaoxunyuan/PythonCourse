SOP8：pandas 综合数据处理与病例分析

怎样从十万条病例中快速获得有意义的统计结果？完成后你将得到「病例数据分析模块」。

1. pandas 基础

import pandas as pd

df = pd.read_csv("data/diabetic_data.csv")
print(df.shape)
print(df.head())
print(df["time_in_hospital"].describe())
print(df["readmitted"].value_counts())

2. 分组、合并与可视化

import matplotlib.pyplot as plt

age_count = df["age"].value_counts().sort_index()
stay_by_age = df.groupby("age")["time_in_hospital"].mean()

age_count.plot(kind="bar")
plt.tight_layout()
plt.savefig("output/age_count.png")
plt.close()

3. 核心实验

  • 不同年龄组病例数量
  • 住院时间分布
  • 不同年龄组住院情况
  • 既往住院次数统计
  • 不同 readmitted 状态病例数量
  • 药物使用情况或住院时间分组比较

至少形成：统计表、分组结果、3～4 张图表、结果文件。
