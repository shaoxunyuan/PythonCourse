SOP11：完整项目集成、测试与交付

把前 10 次实验的代码组合成结构完整、能够运行、能够处理异常的最终项目：《糖尿病住院病例数据分析与智能报告平台》。

1. 推荐项目结构

PythonCourseProject/
├── app.py
├── data/
├── utils/
│   ├── loader.py
│   ├── cleaner.py
│   ├── filter.py
│   ├── analysis.py
│   ├── visualization.py
│   ├── report.py
│   └── llm.py
├── output/
├── requirements.txt
├── README.md
└── .gitignore

2. 最终平台功能

  • 数据导入与概览（记录数、患者数、变量数）
  • 数据质量检查（缺失、异常、编码）
  • 病例查询与筛选
  • 统计分析与可视化
  • 结果导出（筛选结果、统计表、报告）
  • AI 智能摘要（统计由 Python 完成，摘要由大模型生成）
  • 异常处理：文件不存在、格式错误、缺字段、API 失败等都要有清晰提示

3. 依赖、配置与安全

  • 用 requirements.txt 记录依赖
  • API Key 放在环境变量中，不要写入公开代码
  • 使用相对路径访问 data/ 与 output/
  • README 说明：项目名称、功能、环境、安装、运行、目录与模块

4. 验收要点

  • 项目能运行，能读取课程数据
  • 核心功能完整，代码函数化、模块化
  • 页面可交互，分析结果与图表正确
  • API 可调用，或能正确处理调用失败
  • 具备基本异常处理；能解释核心代码，并能现场做一次小修改

5. 作业

最终作业

提交完整项目（含 README、requirements.txt、主要模块与运行说明），作为学期最终作品。
