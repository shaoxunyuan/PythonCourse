SOP6：文件操作与数据格式转换

程序关闭以后数据怎样保存？不同程序之间怎样交换数据？完成后你将得到「病例文件处理器」。

1. 文件读写基础

from pathlib import Path

path = Path("output/summary.txt")
path.parent.mkdir(parents=True, exist_ok=True)
with path.open("w", encoding="utf-8") as f:
    f.write("病例摘要\n")

2. CSV 与 JSON

import csv, json

with open("sample_patients.csv", "r", encoding="utf-8") as f:
    rows = list(csv.DictReader(f))

with open("sample_patients.json", "w", encoding="utf-8") as f:
    json.dump(rows, f, ensure_ascii=False, indent=2)

3. 异常处理

try:
    with open("missing.csv", "r", encoding="utf-8") as f:
        data = f.read()
except FileNotFoundError:
    print("文件不存在")
except Exception as e:
    print("读取失败：", e)

4. 核心实验

实现链路：CSV → Python 数据结构 → JSON → TXT 分析摘要。要求能读取病例、保存病例、导出结果、生成报告。

5. 进阶任务

扫描一个目录中的多个病例文件，自动完成转换与汇总，并写到 output/。

6. 作业

作业 1

完成 CSV↔JSON 双向转换，并生成一份 TXT 摘要。

作业 2

对文件不存在、编码错误、空文件等情况给出清晰提示，程序不崩溃。
