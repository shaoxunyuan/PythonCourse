SOP7：真实病例数据读取、检查与清洗

真实数据为什么不能读取以后直接使用？完成后你将得到「病例数据质量控制系统」。

1. 正式读取真实数据

import csv
from pathlib import Path

data_path = Path("data/diabetic_data.csv")
with data_path.open("r", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    rows = list(reader)

print(len(rows), len(rows[0]))
patients = {r["patient_nbr"] for r in rows}
print(len(patients))

2. 需要检查什么

  • 数据维度、患者数、变量数
  • 缺失值与特殊缺失标记 ?
  • 重复记录、非法值、分类取值是否异常
  • 用 IDS_mapping.csv 解释编码字段
  • 区分 patient_nbr 与 encounter_id

3. 核心实验

读取 diabetic_data.csv，生成 data_quality_report，至少包含：记录数、患者数、变量数、缺失情况、异常情况、字段类型、质量说明。

4. 进阶任务

把质量检查步骤全部封装成函数，例如 check_shape()、check_missing()、check_duplicates()、build_report()。

5. 作业

作业 1

输出完整的数据质量报告（TXT 或 JSON）。

作业 2

结合 IDS_mapping.csv，把 admission_type_id 的取值分布翻译成可读文字统计。
