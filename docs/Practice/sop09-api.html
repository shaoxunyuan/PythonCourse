SOP9：网络请求、大模型 API 与智能报告

Python 怎样调用互联网上的外部服务？完成后你将得到「AI 报告生成模块」：先统计，再生成自然语言摘要。

1. HTTP 与 JSON

  • 客户端 / 服务器、URL、Request / Response
  • GET / POST、Header / Body、状态码
  • requests、JSON 请求与响应
  • API Key 用环境变量读取，不要写死在代码里
