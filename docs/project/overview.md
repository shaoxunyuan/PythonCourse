# 综合项目说明

## 项目目标

围绕同一份真实住院记录数据，逐步建设一个 **Python 数据分析与智能报告平台**。

你最终将能够：

1. 读取并理解课程数据
2. 完成清洗、统计与可视化
3. 调用大模型 API 生成分析摘要
4. 通过 Web 界面展示结果
5. 完成基础在线部署

## 项目与实验的关系

每次 SOP 实验不是孤立练习，而是项目能力的一次升级：

```text
提出问题 → 知识讲授 → 跟随演示 → 学生实践 → 进阶挑战 → 项目升级 → 课后作业
```
