为何要 Web？

命令行脚本
  • 适合开发者本机使用
  • 要装环境、记参数
  • 协作与演示门槛高
Web 应用
  • 浏览器即可交互
  • 上传、点选、看结果
  • 更接近真实工作流
Web 把分析能力包装成「可点击的服务」。

页面里通常有什么？

输入区 文件上传、文本框、选项
操作区 按钮：开始分析、导出
结果区 表格、图片、摘要文本

前后端分工直觉

前端（浏览器）
  • 展示页面与表单
  • 收集用户输入
  • 展示返回的图与文字
后端（服务器 / Python）
  • 接收请求与文件
  • 清洗、统计、出图、调 API
  • 返回 JSON 或生成文件

课程里的数据分析逻辑，主要落在后端模块。

什么叫「可运行交付」？

  • 他人按说明能在约定环境装好依赖
  • 一条（或少数几条）命令能启动
  • 用示例数据能看到完整结果
  • 密钥与隐私按规范配置，不靠口头传授
「我电脑能跑」不等于「已交付」。

常见交付漏洞

  • 路径写死本机盘符，换电脑即失效
  • 依赖装了但版本未记录
  • 只有截图，没有可运行示例
  • 把调试打印当错误处理
  • README 过时，步骤与代码不一致
交付前：换一个干净目录，按 README 重走一遍。
