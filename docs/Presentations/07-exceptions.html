捕获 FileNotFoundError

from pathlib import Path
path = Path("data/diabetic_data.csv")
try:
    with open(path, encoding="utf-8") as f:
        head = f.readline()
except FileNotFoundError:
    print(f"找不到文件：{path.resolve()}")
    head = None
捕获后给出可行动的信息（解析后的绝对路径），比只 print「出错了」有用。

UnicodeDecodeError：编码不对

try:
    with open(path, encoding="utf-8") as f:
        text = f.read()
except UnicodeDecodeError:

  • 也可在打开时用 errors="replace"（会丢信息，仅作权宜）

try / except 基本结构

try:
    # 可能失败的操作
    value = int(text)
except ValueError:
    # 只处理这一类错误
    value = None
  • try：把「可能炸」的最小代码块包起来
  • except 具体类型：避免裸 except: 吞掉所有错误
不要用空的 except: 把真实 bug 藏起来。

finally：无论成败都收尾

f = None
try:
    f = open(path, encoding="utf-8")
    data = f.read()
except OSError as e:
    print("读写失败", e)
    data = ""
finally:
    if f is not None:
        f.close()
    print("收尾完成")
日常文本读写仍优先 with open；理解 finally 有助于写更复杂的资源清理。

错误日志思路

import datetime as dt

def log_bad(path_log, line_no, reason, raw):
    with open(path_log, "a", encoding="utf-8") as log:
        ts = dt.datetime.now().isoformat(timespec="seconds")
        log.write(f"{ts}\tL{line_no}\t{reason}\t{raw[:80]}\n")
  • 记：时间、行号、原因、原始片段
  • 便于事后抽查，而不是只在终端闪一下

综合：读示意 CSV → 统计有效住院日

def load_los(path, log_path):
    ok, values = 0, []
    with open(path, encoding="utf-8") as f:
        next(f)  # 跳过表头
        for i, line in enumerate(f, start=2):
            try:
                los = int(line.split(",")[4])
                if los < 0:
                    raise ValueError("negative")
                values.append(los); ok += 1
            except (ValueError, IndexError) as e:
                log_bad(log_path, i, type(e).__name__, line)
    return values, ok

思考：该不该捕获？

适合捕获
  • 外部输入：文件、用户录入
  • 单行坏数据不影响整批
  • 可恢复：换编码、跳过、默认值
不宜乱捕
  • 自己的逻辑错误（应修代码）
  • 裸 except: 吞掉一切
  • 捕获后静默忽略、无日志

代码：完整骨架（示意）

def safe_load(path):
    path = Path(path)
    if not path.exists():
        raise FileNotFoundError(path)
    rows, bad = [], 0
    with open(path, encoding="utf-8") as f:
        header = f.readline().strip().split(",")
        for i, line in enumerate(f, start=2):
            try:
                row = dict(zip(header, line.strip().split(",")))
                row["time_in_hospital"] = int(row["time_in_hospital"])
                rows.append(row)
            except (KeyError, ValueError):
                bad += 1
    return rows, bad
