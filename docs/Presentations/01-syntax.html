变量：给值起一个名字

encounter_id = 100001
patient_nbr = 8877
time_in_hospital = 5
num_medications = 15
  • 左边是名字，右边是值；= 表示赋值，不是数学相等
  • 名字应能看出含义：天数、药物数、就诊号
变量让后面的计算可以引用同一份数据。
Python高级应用 · 语法与数据类型03

赋值可以覆盖，也可以引用

age = 55
age = 56                    # 覆盖旧值
days = time_in_hospital     # 引用另一个变量
print(age, days)
覆盖

同一名字指向新值，旧值不再通过该名访问

引用

把已有变量的值赋给新名字，便于阅读

整数 int 与浮点 float

time_in_hospital = 5      # int：整天数
num_medications = 15      # int：药物种数
avg = 15 / 5              # float：3.0 日均药物
weight = 72.5             # float：可带小数
int
计数、天数、编号等「完整个」的量
float
除法结果、测量值等带小数的量
注意：/ 在 Python 3 中总是得到 float。

字符串 str：文字与标签

gender = "Female"
readmitted = "<30"
note = 'early readmit'
  • 用单引号或双引号包起来；内容是字符序列
  • 病例里常见：性别、再入院标签、科室名
  • "<30" 是字符串，不是「小于 30」这个比较运算
标签型字段往往先以 str 保存，再按规则解释含义。

布尔 bool 与空值 None

long_stay = True          # 是否长住院
early_readmit = False
middle_name = None        # 尚无该字段 / 未知
bool
  • 只有 True / False
  • 来自比较或逻辑运算
  • 用于分支与筛选
None
  • 表示「没有值」
  • 不同于 0、空字符串
  • 缺字段时常用占位

用 type() 查看类型

print(type(time_in_hospital))   # <class 'int'>
print(type(15 / 5))             # <class 'float'>
print(type(gender))             # <class 'str'>
print(type(long_stay))          # <class 'bool'>
print(type(None))               # <class 'NoneType'>
不确定手里是什么时，先 type()，再决定怎么算。

类型转换：读入后常要「纠正」

days = int("5")
meds = float("15")
label = str(100001)
flag = bool(1)          # True；bool(0) 为 False
int(x)

float(x)
转浮点
str(x)
转成文字，便于拼接与显示
bool(x)

类型决定能做什么操作

合法
5 + 2
"A" + "B"
15 / 5
"<30" == readmitted
常出问题
"5" + 2      # TypeError
int("<30")   # ValueError
True + "天"  # TypeError
先统一类型，再运算；不要把标签字符串当成数字去加减。

算术运算符

a, b = 15, 5
print(a + b, a - b, a * b)   # 20 10 75
print(a / b)                 # 3.0
print(a // b, a % b)         # 3 0 整除与取余
print(2 ** 3)                # 8 幂运算
  • 日均药物：num_medications / time_in_hospital
  • 需要整数份数时用 //；余数用 %

比较运算符 → 得到 bool

time_in_hospital = 5
print(time_in_hospital >= 7)   # False 长住院阈值
print(time_in_hospital == 5)   # True
print(time_in_hospital != 0)   # True
readmitted = "<30"
print(readmitted == "<30")      # True 早期再入院
比较的结果是 True/False，可直接赋给变量或用于筛选。
Python高级应用 · 语法与数据类型12

逻辑运算：and / or / not

long_stay = time_in_hospital >= 7
early = readmitted == "<30"
print(long_stay and early)   # 同时满足
print(long_stay or early)    # 至少一个
print(not early)             # 取反
and两边都真才真
严格联合条件
or有一个真就真
宽松纳入条件
not真变假、假变真
排除某类记录

字符串基础操作

gender = "Female"
print(len(gender))          # 6
print(gender.lower())       # female

  • 拼接用 +；重复用 *（如 "-" * 10）
文本字段清洗前，先弄清大小写与空格。
