参数：位置参数与默认值

def is_long_stay(days, threshold=7):
    return days >= threshold

print(is_long_stay(7))        # 用默认 7
print(is_long_stay(5, 4))     # 临时改阈值
print(is_long_stay(5, threshold=4))
  • 有默认值的参数要放在后面
  • 调用时可用关键字参数，提高可读性

多参数与返回多个值

def med_stats(meds, days):
    avg = meds / days
    dense = avg >= 3
    return avg, dense

a, flag = med_stats(15, 5)
print(a, flag)   # 3.0 True
return a, b 实际返回 tuple；可用解包接收。

*args：接收不定数量位置参数

def mean_days(*days):

  • 适合「个数事先不确定」的同类输入

global：何时（少用）修改全局

counter = 0

def bump():
    global counter
    counter += 1

bump()
print(counter)  # 1
  • 只读全局变量不必写 global
  • 要赋值修改全局名时才声明 global
  • 课堂建议：优先 return 新值，少改全局状态

递归：函数调用自己

def factorial(n):
    if n <= 1:          # 基例：停止条件
        return 1
    return n * factorial(n - 1)  # 向更小规模收敛

print(factorial(5))  # 120
递归两要素：基例 + 问题规模收敛。
Python高级应用 · 函数与模块化12

基例与收敛：缺一不可

正确思路
  • 先写清何时停止
  • 每次调用让参数更接近基例
  • 用小输入手工推演
常见失败
  • 没有基例 → 无限递归
  • 规模不减小 → 栈溢出
  • 可用循环时硬套递归

病例筛选一般用循环更直观；递归作思维训练即可。

def daily_medications(num_medications, time_in_hospital):

        return None
    return num_medications / time_in_hospital

工具箱②：长住院判断

def is_long_stay(time_in_hospital, threshold=7):
    return time_in_hospital >= threshold

def filter_long_stay(encounters, threshold=7):
    return [
        e for e in encounters
        if is_long_stay(e["time_in_hospital"], threshold)
    ]

判断与筛选分层：小组件拼成管道。

工具箱⑤：摘要报告

def summarize(enc):
    avg = daily_medications(
        enc["num_medications"], enc["time_in_hospital"]
    )
    return (
        f"#{enc['encounter_id']} 住院{enc['time_in_hospital']}天 "
        f"日均{avg:.2f} 再入院{enc['readmitted']}"
    )

for e in encounters:
    print(summarize(e))
