为什么要可视化？

只看表格
  • 数字多时难抓重点
  • 趋势、对比不直观

figure 与 axes：画布和坐标系

Figure
整张图的「画布」，可含一个或多个子图
Axes
具体的坐标系：坐标轴、曲线、标题都画在这里
Axis
单根轴（x 或 y），控制刻度与范围
日常说的「画一张图」，多数时候是在操作 Axes。

两种常见写法

pyplot 快捷接口
import matplotlib.pyplot as plt

plt.plot(x, y)
plt.title("趋势")
plt.show()
面向对象接口
fig, ax = plt.subplots()
ax.plot(x, y)
ax.set_title("趋势")
plt.show()

初学可用 plt；多子图、精细控制时更推荐 fig, ax。

三种图怎么选？

折线 时间顺序、连续变化

例：每月病例数趋势
柱状 类别对比、分组计数

例：各科室入院人数
散点 两变量关系、分布

例：年龄与住院天数
先问「要表达什么」，再选图型。

用 Axes 写完整一版

fig, ax = plt.subplots()
ax.plot(months, cases_a, label="A 院区")
ax.plot(months, cases_b, label="B 院区")

ax.set_ylabel("病例数")
ax.legend()

set_title / set_xlabel 对应 pyplot 里的 title / xlabel。

中文显示：常见现象

可能看到什么
  • 标题变成方框 □□□
  • 轴标签缺字、乱码感
  • 负号显示异常
常见原因
  • 默认字体不含中文
  • 系统中文字体名写错
  • 未统一配置字体
中文出图前，先确认字体配置是否生效。

中文显示：配置示意

plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei"]
plt.rcParams["axes.unicode_minus"] = False  # 正常显示负号
  • Windows 上常用「微软雅黑」「黑体」
  • 不同电脑字体名可能不同，需按环境调整
  • 配置写在画图代码之前
原则：选系统已安装、且支持中文的字体。

保存时要注意什么？

格式
.png 清晰通用；.pdf 适合印刷排版
dpi
分辨率；报告插图常用 120–200
bbox_inches

路径
相对/绝对路径，确认工作目录
先 savefig 再 close，避免窗口堆积。

病例统计出图示例

import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["Microsoft YaHei"]
plt.rcParams["axes.unicode_minus"] = False

months = ["1月", "2月", "3月", "4月"]
counts = [120, 135, 128, 150]

fig, ax = plt.subplots()
ax.plot(months, counts, marker="o", label="全院")
ax.set_title("近四月病例数")
ax.set_xlabel("月份")
ax.set_ylabel("病例数")
ax.legend()
fig.savefig("cases_trend.png", dpi=150, bbox_inches="tight")
plt.close(fig)

读图时要自问三句

  • 横轴、纵轴分别是什么？单位清楚吗？
  • 图在支持哪一句结论？
  • 有没有被刻度范围「放大」的假象？
能画出来不等于结论可靠；标签与尺度同样重要。
