Python高级应用 · Matplotlib 数据可视化01

什么是 Matplotlib？

  • Python 最常用的绘图库
  • matplotlib.pyplot 提供简洁的绘图函数
  • 把列表、表格里的数据画成折线、柱状、散点等图表
  • 生成的图片可以放进报告、作业和演示文稿
它的作用很直接：给数据配一张能看懂的图。
Python高级应用 · Matplotlib 数据可视化02

一张图包含什么？

数据
要展示的数值，通常来自两个列表
横轴
类别或自变量，例如星期、社团名
纵轴
对应的数值，例如分钟数、人数
标题
一句话说明这张图画的是什么
图形标记
点、线、柱子，把数值变成可见形状
先想清楚横轴放什么、纵轴放什么，再开始写代码。

加颜色和圆点
import matplotlib.pyplot as plt

days = ["Mon", "Tue", "Wed",
        "Thu", "Fri", "Sat", "Sun"]
minutes = [20, 30, 15,
           40, 35, 60, 45]

plt.plot(days, minutes,
         marker="o",
         color="blue")
plt.show()
  • marker="o"：每个数据点画成圆点
  • color="blue"：指定线条颜色
圆点让「每个数据点在哪」更清楚。

散点图参数

import matplotlib.pyplot as plt

hours = [1, 2, 3, 4, 5, 6]
scores = [56, 60, 65, 74, 79, 86]
plt.scatter(hours, scores,
            s=60, color="teal", alpha=0.8)
plt.show()
s
点的大小，数值越大点越明显
color
点的颜色，可用颜色名或色值
alpha
透明度，0 完全透明，1 完全不透明
参数用来突出重点，不必一次记住所有取值。

网格与图表可读性

import matplotlib.pyplot as plt

days = ["Mon", "Tue", "Wed",
        "Thu", "Fri", "Sat", "Sun"]
minutes = [20, 30, 15,
           40, 35, 60, 45]

plt.plot(days, minutes, marker="o", color="blue")
plt.grid(True, alpha=0.3)
plt.show()
  • plt.grid(True)：显示辅助网格线
  • alpha=0.3：让网格浅一些，不抢数据
  • 网格帮助读者对齐数值，不是主角
可读性的标准：不用解释，也能看懂图在说什么。

保存与显示图表

import matplotlib.pyplot as plt

days = ["Mon", "Tue", "Wed",
        "Thu", "Fri", "Sat", "Sun"]
minutes = [20, 30, 15,
           40, 35, 60, 45]

plt.plot(days, minutes,
         marker="o", color="blue")
plt.title("Weekly Exercise Time")
plt.xlabel("Day")
plt.ylabel("Minutes")
plt.grid(True, alpha=0.3)
plt.savefig("exercise10.png",
            dpi=150,
            bbox_inches="tight")
plt.show()
savefig 放在 show 之前，图片写入当前工作目录。
