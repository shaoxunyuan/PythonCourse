完整代码：一起来运行

class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def get_level(self):
        if self.score >= 90: return "优秀"
        elif self.score >= 80: return "良好"
        elif self.score >= 60: return "及格"
        else: return "不及格"

    def show(self):
        print(self.name, self.score, self.get_level())

for student in [Student("张三", 85), Student("李四", 72), Student("王五", 93)]:
    student.show()

什么时候值得自己定义一个类？

  • 只是求三个数字的平均值：通常直接写函数就够了
  • 程序里有很多学生，每位学生都保存姓名、成绩
  • 每位学生都要查询等级、显示信息、修改成绩
  • 这些数据和操作经常一起出现时，可以考虑 Student 类
类不是必须使用的语法，而是一种代码组织选择。

回顾：今天真正需要记住什么？

  • 面向过程：先考虑任务分成哪些步骤
  • 面向对象：先考虑有哪些对象、它们有什么和能做什么

  • self 指当前对象；self.name 是对象的属性
