换行符 \n 是什么？

代码里的字符串
"张三,85\n李四,72\n王五,93\n"
文件里看到的样子
张三,85 李四,72 王五,93

源代码中的 \n 是转义符；落到文件里就变成真正的换行。

def get_level(score):
    if score >= 90: return "优秀"
    elif score >= 80: return "良好"

为什么还要 CSV？

普通逗号文本
张三,85 李四,72 王五,93
带表头的 CSV
name,score 张三,85 李四,72 王五,93

CSV 是文本格式：标准化的列与记录，可用表格软件查看；它并不等于 Excel 专有格式。

用 csv.writer() 写表格

import csv

with open("students.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["name", "score"])
    for s in students:
        writer.writerow([s["name"], s["score"]])
students.csv：name,score 表头 + 三行数据

newline="" 可避免 Windows 上多余空行；字段含逗号/引号时，标准库会帮你处理转义。

TXT、CSV、JSON 怎么选？

TXT 自由文本、简单行记录

优点：直观
局限：要自己解析
CSV 行列记录、表头明确

优点：表格软件友好
局限：难表达嵌套
JSON 嵌套结构、对象数据

优点：结构可还原
局限：人工编辑稍繁
没有绝对优劣，按数据怎么组织来选。

什么是格式化输出？

普通 print
print(name, score) # 张三 85
f-string
print(f"{name}：{score} 分") # 张三：85 分
格式化让结果更好读；它不改变原始成绩。打印是呈现，保存到文件还要另一步。

小数精度、宽度与对齐

average = 83.3333
print(f"{average:.2f}")   # 83.33   显示两位小数
print(f"{score:>5}")      #   85   宽度 5，右对齐
  • .2f 只影响显示，不修改 average 本身
  • 中文宽度不一定等于「看起来的字符宽度」
