los = 12

    label = "长住院"
else:
    label = "常规住院"

条件为真走 if，否则走 else；每次只执行一条路径。

思考：条件顺序为什么重要？

易错写法
if los >= 5:
    level = "中等"
elif los >= 10:
    level = "较长"  # 永远到不了
稳妥写法
if los >= 14:
    ...
elif los >= 10:
    ...
elif los >= 5:
    ...
先写更具体 / 更窄的条件，再写更宽的；顺序即优先级。

while：条件成立就继续

i = 0
long_stays = []
while i < len(cases):
    if cases[i]["los"] >= 10:
        long_stays.append(cases[i]["id"])
    i += 1
print(long_stays)  # ['C01']
务必推进循环变量（如 i += 1），否则可能死循环。

思考：for 还是 while？

更常用 for
  • 已知要遍历的集合
  • 病例列表、字段列表
  • 配合 range 固定次数
适合 while
  • 结束条件由运行时决定
  • 「读到空行再停」类逻辑
  • 重试直到成功或达上限
病例批处理多数场景：for case in cases 更自然。

组合：筛选后再统计

n_f = 0
n_readmit_f = 0
for case in cases:
    if case["sex"] != "F":
        continue
    n_f += 1
    if case["readmit_30d"]:
        n_readmit_f += 1
rate = n_readmit_f / n_f if n_f else 0
print(n_f, n_readmit_f, rate)  # 2 2 1.0
先缩小集合，再在子集上计数——控制流的典型套路。

规则一：长住院标记

def flag_long_stay(case, threshold=10):
    return case["los"] >= threshold

alerts = []
for case in cases:
    if flag_long_stay(case):
        alerts.append(case["id"])
print(alerts)  # ['C01']

把阈值收进函数，阈值变更时只改一处。

规则三：性别与住院天数

stats = {"F": {"n": 0, "los_sum": 0},
         "M": {"n": 0, "los_sum": 0}}
for case in cases:
    g = case["sex"]
    if g not in stats:
        continue
    stats[g]["n"] += 1
    stats[g]["los_sum"] += case["los"]

for g, s in stats.items():
    avg = s["los_sum"] / s["n"] if s["n"] else 0
    print(g, s["n"], round(avg, 1))

一次遍历：多规则处理器

def process_cases(cases, los_th=10):
    out = {"long": [], "early": [], "by_sex": {}}
    for case in cases:
        g = case["sex"]
        out["by_sex"][g] = out["by_sex"].get(g, 0) + 1
        if case["los"] >= los_th:
            out["long"].append(case["id"])
        if case["readmit_30d"]:
            out["early"].append(case["id"])
    return out

print(process_cases(cases))
