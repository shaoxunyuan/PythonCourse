Python高级应用 · NumPy 数组与数值计算02

为什么要用 NumPy？

list 循环
los = [3, 5, 12, 2, 8]
s = 0
for x in los:
    s += x
avg = s / len(los)
NumPy
import numpy as np
los = np.array([3, 5, 12, 2, 8])
avg = los.mean()
写法更短；大数据量时通常更快，且便于矩阵式运算。

向量化 vs 循环

循环
out = []
for x in los:
    out.append(x * 2)
out = np.array(out)
向量化
out = los * 2
# 每个元素同时 ×2
能写成数组表达式时，优先向量化：更清晰，也通常更快。

统计：mean / sum / max

los = np.array([3, 5, 12, 2, 8, 6, 4])
print(los.mean())   # 平均住院日

这些方法直接作用在数组上；二维时可指定 axis。

axis 直觉（二维示意）

# 行：患者；列：两次住院天数
X = np.array([[3, 5],
              [7, 2],
              [10, 8]])
print(X.mean(axis=0))  # 各列平均 → 两次住院的总体均值
print(X.mean(axis=1))  # 各行平均 → 每位患者均值
口诀：axis=i 表示「沿着 i 这个方向压缩」。

从 Python 列表安全转换

raw = ["3", "5", "NA", "12", "2"]
vals = []
for x in raw:
    try:
        vals.append(int(x))
    except ValueError:
        continue
los = np.array(vals, dtype=np.int64)
print(los, los.mean())

脏数据先在 Python 层清洗或过滤，再进入 ndarray。

代码：住院日描述函数

def describe_los(los):
    los = np.asarray(los, dtype=float)
    return {
        "n": los.size,
        "mean": float(los.mean()),
        "max": float(los.max()),
        "p_long": float((los >= 10).mean()),
    }

print(describe_los([3, 5, 12, 2, 8, 14]))
