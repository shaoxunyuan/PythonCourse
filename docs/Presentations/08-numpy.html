两种思维：逐个处理 vs 整体操作

逐个处理：for 循环
los = [3, 5, 12]
out = []
for x in los:
    out.append(x * 2)
# 描述“每一步怎么做”

import numpy as np
los = np.array([3, 5, 12])
out = los * 2
# 描述“结果是什么”
同一件事，左边关心过程，右边直接表达结果——这就是本次思维切换。

ndarray 的身体结构：四个属性

x = np.array([[3, 5, 12], [2, 8, 6]])
print(x.ndim, x.shape, x.dtype, x.size)
ndim
维度个数，也就是“有几个轴”
shape
每一维的长度，元组；本例 (2, 3)
dtype
元素类型，整个数组统一
size
元素总数，等于 shape 各维相乘

创建数组与 dtype

a = np.array([3, 5, 12, 2, 8])
b = np.zeros((2, 3))          # 2×3 浮点 0

索引与切片：一维与二维

a = np.array([3, 5, 12, 2, 8, 6, 4])
m = np.array([[3, 5, 12],
              [2, 8, 6]])

逗号前是行、逗号后是列；冒号表示“这一维全要”。取完先看结果的 shape。
Python高级应用 · NumPy 数组与数值计算07

视图 vs 副本：改的是不是原数据

m = np.array([[3, 5, 12],
              [2, 8, 6]])
v = m[0]            # 视图
v[0] = 99
print(m[0])         # [99 5 12] 原数组被改
c = m.copy(); c[0, 0] = 1
print(m[0, 0])      # 99 副本独立
切片返回视图，赋值会写回原数组；需要独立数据就用 .copy()。
布尔掩码与花式索引返回的是副本，不是视图。

布尔掩码：按条件取子数组

los = np.array([3, 5, 12, 2, 8, 6, 4])
mask = los >= 8
print(mask.shape)      # (7,) 与原数组同形状
print(los[mask])       # [12 8]

m = np.array([[3, 5, 12],
              [2, 9, 6]])
print(m[m[:, 1] >= 8]) # [[2 9 6]] 按列条件选行
mask 与原数组同形状；放进方括号就是筛选。按列条件选行：先取一列得到 mask，再按行取。

向量化：让 for 从代码里消失

los = np.array([3, 5, 12, 2, 8])
print(los + 1)        # [4 6 13 3 9]
print(los * 2)        # [6 10 24 4 16]
z = (los - los.mean()) / los.std()
print(z.round(2))
标量与数组运算会作用到每个元素；整条表达式串起来，仍然没有循环。

为什么向量化更好

循环：逐元素搬
import numpy as np
los = np.array([3, 5, 12])
out = []
for x in los:
    out.append((x - 3) ** 2)
out = np.array(out)
数组：整体表达
import numpy as np
los = np.array([3, 5, 12])
out = (los - 3) ** 2
写法更短、意图更清楚；性能来自底层 C 循环，通常更快，但不必夸大或背数字。

聚合：把整个数组压成一个数

los = np.array([3, 5, 12, 2, 8, 6, 4])
print(los.sum())    # 40
print(los.mean())   # 5.714285...
print(los.max())    # 12
print(los.min())    # 2
print((los >= 8).mean())  # 0.2857 长住院占比
默认对全部元素聚合，不需要循环；布尔数组求 mean，就是满足条件的比例。

axis 聚合：哪一维被压掉

X = np.array([[3, 5], [7, 2], [10, 8]])
print(X.sum(axis=0))   # [20 15] 每列
print(X.sum(axis=1))   # [8 9 18] 每行
print(X.mean(axis=0).shape)  # (2,)
axis 指“被压掉的那一维”：axis=0 压掉行，按列汇总；axis=1 压掉列，按行汇总。
记忆法：结果 shape = 原 shape 去掉 axis 这一维。

广播规则：三条

01
从尾部对齐：两个 shape 的右端先对齐
02
逐维比较：相等，或其中一个是 1，才算兼容
03
1 可扩展：长度为 1 的那一维，复制到另一侧的长度
三条同时成立才能算。先写 shape 推演，再写代码；例：(2,3) 与 (3,) → (1,3) → (2,3)。
Python高级应用 · NumPy 数组与数值计算15

广播示例：行向量与列向量

X   = np.array([[1, 2, 3],
                [4, 5, 6]])      # (2, 3)
row = np.array([10, 20, 30])     # (3,)  → (1, 3)
col = np.array([[1], [2]])       # (2,1) → (2, 3)
print((X + row).shape)           # (2, 3)
print((X + col).shape)           # (2, 3)
print(X + col)                   # 每行加 1 / 加 2
推演：(2,3) 与 (3,) 右对齐成 (2,3)/(1,3)，逐维兼容 → (2,3)。行向量按行铺，列向量按列铺。

广播失败：读报错，修形状

X = np.array([[1, 2, 3],
              [4, 5, 6]])        # (2, 3)
y = np.array([10, 20])           # (2,)
# X + y → ValueError: shapes (2,3) and (2,)
print((X + y[:, None]).shape)    # (2, 3)
print((X + y.reshape(2, 1)).shape)  # (2, 3)
尾维 3 与 2 无法对齐 → 报错。[:, None] 或 reshape 把 y 变成 (2,1)，不要改函数名。

小矩阵验证法：3×2 走一遍

m = np.array([[3, 5],
              [2, 9],

综合小流程：住院天数

los = np.array([[3, 5],
                [2, 9],
                [8, 6]])              # (3, 2)
print(los.shape)                  # (3, 2)
print(los[los >= 8])              # [9 8]
print(los.mean(axis=0))           # [4.33 6.67]
z = (los - los.mean(axis=0)) / los.std(axis=0)
print(z.shape)                    # (3, 2) 按列广播
顺序：shape → mask → 按列聚合 → 广播标准化；每一步都检查形状。

常见坑：四类

形状不匹配
(3,) 与 (3,1) 不同，广播前先右端对齐
视图改原数据
切片赋值会写回；需要独立数据用 .copy()
axis 搞反
想按行汇总却写了 axis=0；先问“压掉哪一维”
dtype 截断
整数数组存小数会截断；求均值前先转 float
这四类错误的共同点：动手前没看形状 / 类型。
