索引：按位置取出元素

days = [5, 8, 3, 12, 7]
print(days[0])    # 5  第一个
print(days[2])    # 3
print(days[-1])   # 7  最后一个
print(days[-2])   # 12
索引越界会 IndexError；先看 len 再取。
Python高级应用 · 组合数据类型05

切片：取出一段子序列

days = [5, 8, 3, 12, 7]
print(days[1:4])   # [8, 3, 12] 含头不含尾
print(days[:3])    # [5, 8, 3]
print(days[3:])    # [12, 7]
print(days[::2])   # [5, 3, 7] 步长 2
切片得到新列表，一般不修改原列表。
Python高级应用 · 组合数据类型06

增、删、改

days = [5, 8, 3]
days.append(12)      # 末尾追加 → [5, 8, 3, 12]
days.insert(1, 6)    # 在下标 1 插入
days[0] = 4          # 修改
days.pop()           # 弹出最后一个
days.remove(8)       # 按值删除首次出现
  • append / extend 变长；赋值改内容
  • pop(i) 按位置；remove(x) 按值

list 常用查询

days = [5, 8, 3, 8]
print(8 in days)        # True
print(days.count(8))    # 2
print(days.index(3))    # 2
print(sorted(days))     # [3, 5, 8, 8] 新列表
days.sort(reverse=True) # 原地降序
分清：sorted 返回新列表；sort 改原列表。

tuple：有序但不可变

record_key = (100001, 8877)   # 就诊号 + 患者号
print(record_key[0])
# record_key[0] = 9  → TypeError
适合
  • 坐标、键、固定配对
  • 不想被误改的常量组
  • 字典的键（元素需可哈希）
对比 list
  • tuple 用圆括号
  • 创建后不能增删改元素
  • 可索引、可切片

dict：用键访问字段

encounter = {
    "encounter_id": 100001,
    "patient_nbr": 8877,
    "gender": "Female",
    "time_in_hospital": 5,
    "num_medications": 15,
    "readmitted": "<30"
}
读字段：encounter["gender"]；比「记住第几个位置」更稳。
Python高级应用 · 组合数据类型10

dict 的读、写、删

print(encounter["readmitted"])
encounter["age"] = 55              # 新增或覆盖
encounter["time_in_hospital"] = 6  # 修改
print(encounter.get("bmi", None))  # 缺键时给默认
del encounter["age"]               # 删除键
  • 直接 d[k] 缺键 → KeyError
  • get 更适合「可能缺失」的字段

set：不重复的集合

labels = {"<30", ">30", "NO", "<30"}
print(labels)              # 自动去重
print("<30" in labels)     # True 成员判断快
labels.add("OTHER")
labels.discard("OTHER")
  • 无序、元素唯一；适合去重与集合运算
  • set(list) 可对列表快速去重
再入院标签的合法取值，很适合用 set 描述。

选型：四种结构怎么选？

list有序、要改、按位置取
一批住院天数
tuple有序、不改
固定主键配对
dict按名字取字段
一条就诊记录
set：只要「有没有、去重」，不要重复与顺序时。

多条就诊：常用「字典的列表」。

嵌套：结构里再放结构

patient = {
    "patient_nbr": 8877,
    "gender": "Female",
    "encounters": [100001, 100088]

print(patient["encounters"][0])
外层 dict 管患者；内层 list 管多次就诊号。

list of dict：多条就诊的标准形状

encounters = [
    {"encounter_id": 100001, "time_in_hospital": 5,
     "num_medications": 15, "readmitted": "<30"},
    {"encounter_id": 100002, "time_in_hospital": 9,
     "num_medications": 22, "readmitted": "NO"},
]
  • 每一行（每个 dict）字段名一致，便于循环处理
  • 取第二条住院天数：encounters[1]["time_in_hospital"]

模型①：单条记录用 dict

def show(enc):
    print(enc["encounter_id"], enc["gender"],
          enc["time_in_hospital"], enc["readmitted"])

row = {
    "encounter_id": 100001, "patient_nbr": 8877,
    "gender": "Female", "age": 55,
    "time_in_hospital": 5, "num_medications": 15,
    "readmitted": "<30"
}
show(row)

模型②：从表格式行到 dict

header = ["encounter_id", "patient_nbr", "gender",
          "age", "time_in_hospital", "num_medications", "readmitted"]
row = [100001, 8877, "Female", 55, 5, 15, "<30"]
enc = dict(zip(header, row))
print(enc["num_medications"])
zip + dict：把「表头 + 一行」变成字段字典。

模型③：批量计算日均药物

for enc in encounters:
    avg = enc["num_medications"] / enc["time_in_hospital"]
    enc["daily_meds"] = round(avg, 2)

long_stays = [
    e for e in encounters if e["time_in_hospital"] >= 7
]
  • 在原 dict 上增加派生字段 daily_meds
  • 用列表推导筛选长住院记录

模型④：早期再入院集合

early_ids = {
    e["encounter_id"]
    for e in encounters
    if e["readmitted"] == "<30"
}
print(100001 in early_ids)
set 存就诊号：去重 + 快速判断「是否早期再入院队列」。
