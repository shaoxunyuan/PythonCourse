# 课程数据说明

本目录存放《Python 高级应用》课程的统一实验数据。

## 文件列表

| 文件名 | 作用 |
|--------|------|
| `diabetic_data.csv` | 主数据：住院记录（encounter）明细 |
| `IDS_mapping.csv` | 辅助编码说明：解释部分数字编码字段的含义 |

## 数据概况

- `diabetic_data.csv`：**101,766 行 × 50 列**
- 不同 `patient_nbr` 数量：**71,518**
- 一行 = **一次住院记录**，不是一名唯一患者
- `IDS_mapping.csv`：**67 行数据 + 表头**，共 2 列（编码与描述）

更完整的介绍见课程网站页面：[SOP0：认识我们的课程数据](../docs/sop0-data.md)。

## 数据来源

本数据集基于公开的糖尿病住院相关教学/研究数据整理，用于程序设计与数据分析教学。

## 使用说明

1. 课程页面需要下载数据时，请直接链接到本目录中的原始文件，不要把大文件再复制一份到 `docs/assets/`。
2. 本地实验时，建议从仓库根目录读取，例如：`data/diabetic_data.csv`。
3. 早期实验可能先使用少量病例样本，再逐步过渡到完整数据。

## 重要声明

本数据仅用于 Python 编程、数据处理和软件开发教学。

课程中的病例筛选规则、统计结果以及大模型生成内容，均不用于临床诊断、治疗决策或真实医疗活动。
